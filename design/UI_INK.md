# หน้าตายุทธภพ: กระดาษ หมึก ตราชาด

แนวทาง ก. ที่ผู้เล่นเลือก — คงโครงหน้าจอเดิมทั้งหมด แต่ทำให้ "เหมือนมีคนลงมือทำ" ไม่ใช่แม่แบบสำเร็จรูป

## สิ่งที่ศึกษามา (ย่อ)

- UI แนวหมึกที่ดี (shuimo-ui, 绘真·妙笔千山) ได้ความรู้สึกมือทำจาก **ขอบที่ไม่เรียบ** (เส้นพู่กันวาดเป็นภาพ) และ **เนื้อกระดาษจริง** ไม่ใช่เส้นขอบ CSS ตรงๆ — เราใช้ฟิลเตอร์ SVG (feTurbulence + feDisplacementMap) ทำขอบหยักแทนภาพวาด
- สีเน้นมีสีเดียว ไม่เกินราว 30% ของจอ ที่เหลือคือหมึก กระดาษ และเทา (uisdc)
- หนึ่งจุดสนใจต่อหน้าจอ · เนื้อหาอยู่บน การกระทำอยู่ล่างทุกหน้า · เว้นที่ว่างให้หายใจ
- ภาษาไทยอ่านง่ายที่ 15–16px ตัวมีหัว (ผู้อ่านไทยชอบตัวอักษรแบบดั้งเดิม) · สระบน-ล่างซ้อนต้องการระยะบรรทัดมากกว่าละติน → 1.7–1.75
- ห้าม: อีโมจิ ไล่สีพื้นหลังจัด กล่องมุมมนขอบซ้ายสี ชิปทรงยาเม็ด แสงเรืองแบบนีออน

## ตัวอักษร

- หัวเรื่อง ชื่อคน ตัวเลขอายุ: **Chonburi** (ตัวหนาหัวกลมมีปลาย) — ใช้เฉพาะหัวเรื่อง ไม่เคยใช้กับเนื้อความ
- เนื้อเรื่อง: **Noto Serif Thai** 15–15.5px ระยะบรรทัด 1.72–1.75
- ป้ายเล็ก ตัวเลข สถานะ: **IBM Plex Sans Thai** 11.5–13px ตัวเลขแบบกว้างเท่ากัน

## วัสดุ

1. **กระดาษ**: เม็ดละเอียด (noise ความถี่สูง) + ลายเส้นใยกระดาษ (noise ความถี่ต่ำ ยืดแนวนอน) + ขอบจอหมองนิดเดียว
2. **เส้นพู่กัน**: เส้นคั่นเป็นภาพ SVG เส้นหัวท้ายเรียว ขอบหยัก — แทนเส้น 1px ตรงๆ ในตำแหน่งสำคัญ
3. **ตราชาด**: อายุ ปุ่มหลัก ตราผลลัพธ์ — สี่เหลี่ยมแดงขอบหยัก มีจุดหมึกไม่ติดเล็กน้อย ตัวอักษรขาวแบบ白文
4. **กรอบ**: แผ่นป้ายส่วนหัวและหน้าต่างเหตุการณ์ใช้กรอบเส้นหมึกขอบหยัก (ฟิลเตอร์ใส่ที่ชั้นพื้นหลังเท่านั้น ตัวหนังสือคมเสมอ)

## การเคลื่อนไหว (ใช้น้อย แต่ให้รู้สึก)

- บันทึกใหม่: หมึกซึม (จางและเบลอนิดๆ → คม) 350ms
- หน้าต่างเหตุการณ์: คลี่ออก 220ms · ตัวเลือกค่อยๆ ขึ้นทีละข้อ 40ms
- ผลลัพธ์: ตราประทับ "สำเร็จ / พลาด" กดลงพร้อมเด้งเล็กน้อย 260ms
- อายุเปลี่ยน: ตราอายุประทับใหม่
- ผู้ใช้ที่ปิดการเคลื่อนไหว: ไม่มีทั้งหมด

## กติกาที่ตรวจทุกหน้าจอ

- ไม่มีอีโมจิในส่วนติดต่อ (เว้นเครื่องหมายเพศ)
- สีชาดเฉพาะ: อายุ ปุ่มหลัก ตัวกรองที่เลือก อันตราย/เสียหาย หัวภาค
- มุมโค้งไม่เกิน 4px ยกเว้นแผ่นเลื่อนด้านบน
- ทุกปุ่มแตะได้อย่างน้อย 44px · ตัวหนังสือผ่าน 4.5:1 บนกระดาษ
- ไม่มีกล่องซ้อนกล่อง: แยกส่วนด้วยเส้นและที่ว่างก่อน กรอบใช้เมื่อจำเป็นเท่านั้น

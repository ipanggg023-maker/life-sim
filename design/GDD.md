# Life Sim (ชื่อชั่วคราว) — Game Design Document

> เอกสารรวมการตัดสินใจจากการ grill · อัปเดตล่าสุด 2026-10-16

## 1. ภาพรวม

- **แนว:** life simulator แบบ BitLife (text-based) ผสม trope มังฮวา/มังฮัว/ไลท์โนเวลหลายร้อยเรื่อง
- **แพลตฟอร์ม:** เว็บเกม responsive (mobile-first) เล่นได้ทั้งมือถือและคอม
- **เป้าหมาย:** ทำเล่นเอง + แชร์ให้เพื่อนเล่น
- **ภาษา:** ไทยเป็นหลัก เก็บข้อความ/event เป็นไฟล์ข้อมูล (JSON) เพื่อเพิ่มภาษา/โลกภายหลัง
- **ลิขสิทธิ์:** ใช้ *trope* ได้เต็มที่ ห้ามใช้ชื่อตัวละคร/ชื่อเรื่องจริง

## 2. การตัดสินใจหลัก

| # | หัวข้อ | การตัดสินใจ |
|---|---|---|
| 1 | แพลตฟอร์ม | เว็บ responsive |
| 2 | โลก/ภาษา | ไทยเป็นหลัก โครงสร้างรองรับหลายโลก/ภาษา |
| 3 | โครงสร้างโลก | **หลายโลก** + วิญญาณที่เก็บของข้ามชาติ |
| 4 | โลกแรก | Hunter/Gate → ยุทธภพ → ราชสำนักแฟนตาซี (โลก 4+ เพิ่มภายหลัง) |
| 5 | จังหวะเวลา | **+1 ปีเป็นแกนหลัก** + **ตอนพิเศษ (Episode)** หลายจังหวะสำหรับเหตุการณ์ใหญ่ |
| 6 | การตาย | ตายจริง ไม่มีซื้อชีวิต — แต่การตายคือกลไกหลัก (ย้อนเวลา/เกิดใหม่) · ฉากเสี่ยงต้องมีคำเตือนอัตรารอด |
| 7 | ของข้ามชาติ | 3 ชั้น: **ความทรงจำ** (แรงสุด) · **แต้มวิญญาณ** (กลาง) · **ปลดล็อกถาวร** (ไม่เพิ่มพลัง) |
| 8 | ความยาวเกม | เล่นได้ไม่รู้จบ ไม่มี Game Over · การย้อนเวลาในโลกเดียวมีราคา (อนาคตเพี้ยน/ย้อนได้ไม่ไกลเท่าเดิม) |
| 9 | ตัวร้ายย้อนเวลา | มี แต่หายาก และเข้าเฟสหลัง |
| 10 | ครอบครัว | สร้างครอบครัวได้เต็มที่ แต่ผู้เล่นคือวิญญาณเสมอ ครอบครัวกลายเป็น **มรดก** ในโลกนั้น |
| 11 | แกนเวลา 2 แบบ | **ย้อนเวลา** (อดีตของชาติเดิม) / **เกิดใหม่** (ยุคถัดไปของโลกเดิม หรือโลกอื่น) |
| 12 | การเกิด | ผู้เล่น **สุ่มเกิดเท่านั้น** · Admin/dev mode สร้างตัวละครแบบ D&D ได้ |
| 13 | แต้มวิญญาณ | ใช้ **เพิ่มดวง** ไม่ใช่เลือกเอง: เพิ่มโอกาสของหายาก, reroll 1 ครั้ง, ล็อกพรสวรรค์ 1 อย่างจากชาติก่อน |
| 14 | พรสวรรค์ | เห็น 1–2 อย่างตอนเกิด + **ช่องลับ ???** เปิดเมื่อตื่นพลัง/เฉียดตาย/ครบอายุ · มีพรสวรรค์ดาบสองคม |
| 15 | เลือกโลกตอนเกิด | ชาติแรกเป็นโลก Hunter เสมอ (บทเรียน) · ต่อไปเลือกได้ว่า ย้อนเวลา / เกิดใหม่โลกเดิม / สุ่มโลกใหม่จากโลกที่ปลดล็อกแล้ว |
| 16 | สเตตัส | 3 ชั้น: **ชีวิต** (หลอด 0–100: สุขภาพ, ความสุข, สติปัญญา, รูปลักษณ์, โชคแบบซ่อน) · **พลัง** (แรงก์ F→SSS + เลเวล, ชื่อเรียกต่างกันตามโลก) · **สังคม** (เงิน, ชื่อเสียงที่ติดลบได้, ค่าความสัมพันธ์รายคน) · ไม่มี STR/AGI ในช่วงแรก |
| 17 | ผู้เล่น | เล่นคนเดียว ทั้งคอมและมือถือ (iOS) ไม่มีอันดับคะแนนหรือ multiplayer |
| 18 | โฮสต์ | Deploy ฟรีบน GitHub Pages/Netlify + ทำเป็น **PWA** (เพิ่มไปหน้าจอโฮม iOS ได้, เล่นออฟไลน์ได้) |
| 19 | เซฟ | เซฟอัตโนมัติทุก +1 ปี · ย้ายข้ามเครื่องด้วย **Export/Import (รหัส + QR code)** · ซิงก์คลาวด์เพิ่มทีหลังได้ · เก็บประวัติชาติก่อนๆ (บันทึกวิญญาณ) |

### ข้อควรระวังบน iOS

- ติดตั้งผ่าน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- iOS อาจล้างข้อมูลเว็บได้ → ขอ `navigator.storage.persist()` และเตือนให้ export เซฟสำรองเป็นระยะ
- iOS ไม่รองรับ Vibration API → ใช้หน้าจอสั่นแทนการสั่นเครื่อง
- ต้องเผื่อพื้นที่รอยบาก/Dynamic Island (`safe-area-inset`)
- เสียงเล่นได้หลังผู้เล่นแตะหน้าจอครั้งแรกเท่านั้น

## 3. คลัง Trope (จากการค้นคว้า)

### 3.1 มังฮวาเกาหลี

| กลุ่ม | trope เด่น | ใช้ในเกมเป็น |
|---|---|---|
| **Hunter / Gate / System** | ตื่นพลังแรงก์ E–S, Gate break, Red Gate, ดันเจี้ยนคู่, กิลด์, ตื่นพลังรอบสอง, หน้าต่างระบบส่วนตัว | โลก 1 |
| **Regression / Returnee** | ตายแล้วย้อนไปตอนหนุ่ม, ใช้ความรู้อนาคต, ย้อนครั้งที่ 100 | กลไกหลักทั้งเกม |
| **Murim** | สำนักฝ่ายธรรมะ/อธรรม/ลัทธิมาร, ลมปราณ/ตันเถียน, คัมภีร์ในถ้ำ, ปรมาจารย์ซ่อนตัว, ประลองยุทธ์, ปรมาจารย์กลับมาเกิดในสำนักตัวเอง | โลก 2 |
| **Romance Fantasy** | ทะลุมิติเข้านิยายเป็นคุณหนูตัวร้าย, death flag, หมั้นหมาย/ถอนหมั้น, ดยุก, สัญญาแต่งงาน, นักบุญหญิง, งานน้ำชา | โลก 3 |
| **ย้อนเวลามาเป็นลูกแชโบล** | เกิดใหม่เป็นลูกคนเล็ก, รู้ว่าหุ้นตัวไหนพุ่ง, สงครามมรดก, ล้างแค้นตระกูล | โลกที่ 4 (เวอร์ชันโลกปัจจุบันที่ไม่มีพลัง) |
| **Apocalypse / ผู้อ่านนิยาย** | โลกกลายเป็น "ฉากภารกิจ", มีผู้สนับสนุนบนฟ้าคอยดู, เหรียญ, ผู้อ่านที่รู้ตอนจบ | โลกที่ 5 + ระบบผู้สนับสนุน |
| **ปีนหอคอย** | ชั้นต่อชั้น, การทดสอบ, ผู้คัดเลือก | โลกที่ 6 |
| **Academy** | ทะลุมิติเป็นตัวประกอบในเกม, จัดอันดับนักเรียน, อัจฉริยะประจำตระกูล | โลกที่ 7 |
| **สร้างอาณาจักร/พัฒนาที่ดิน** | ใช้ความรู้วิศวกรรมยุคใหม่พลิกที่ดินล้มละลาย | event สายบริหาร |
| **Barbarian/Game survival** | ติดอยู่ในเกมที่เคยเล่น, เอาตัวรอดแบบโหด | สุ่มเป็นจุดเริ่มพิเศษ |
| **อาชีพย้อนเวลา** | ย้อนมาเป็นหมอ, เชฟ, นักแสดง, ไอดอล, นักเทรด | **สะพานเชื่อม BitLife** — อาชีพในโลกปัจจุบัน |
| **ชีวิตโรงเรียน/ต่อยตี** | สลับร่าง, สู้ในโรงเรียน, แก๊ง | event วัยเรียน |
| **สยองขวัญ** | คนกลายเป็นสัตว์ประหลาด, ขังอยู่ในตึก | Episode พิเศษ |

### 3.2 มังฮัวจีน (Cultivation / Xianxia)

- ขั้นบำเพ็ญ (ก่อลมปราณ → สร้างฐาน → แก่นทอง → ทารกวิญญาณ …), ทัณฑ์สวรรค์ตอนเลื่อนขั้น
- รากวิญญาณ, ปรุงยาเม็ด, ศิษย์นอก/ศิษย์ใน/ศิษย์สายตรง
- **ตบหน้า (face-slap):** นายน้อยหยิ่งยโสดูถูกพระเอก แล้วโดนตบหน้ากลับ
- ถอนหมั้นต่อหน้าคนอื่น ("สามสิบปีฝั่งตะวันออก สามสิบปีฝั่งตะวันตก")
- **พบวาสนา:** ตกหน้าผาแล้วเจอคัมภีร์หรือผู้เฒ่าในแหวน
- ใช้เป็นโลก "เซียน" (ขยายจากยุทธภพ) หรือเป็นจักรวาลเดียวกับยุทธภพในยุคหลัง

### 3.3 ไลท์โนเวล/มังงะญี่ปุ่น (Isekai)

- โดนรถบรรทุกชนแล้วไปเกิดต่างโลก
- เกิดเป็นสไลม์, มอนสเตอร์ หรือดาบ (จุดเริ่มที่ไม่ใช่มนุษย์)
- สกิลขยะที่กลายเป็นโกง
- โดนไล่ออกจากปาร์ตี้ฮีโร่ แล้วกลับมาเก่งกว่าเดิม
- ใช้ชีวิตช้าๆ ในต่างโลก (slow life / ทำฟาร์ม)
- เกมจีบหนุ่มในบทคุณหนูตัวร้าย (otome)

### 3.4 ไอเดียไทย (จุดขายเฉพาะ)

- โลก **"มิติลี้ลับไทย"**: ไสยศาสตร์, ผี, ของขลัง, เวรกรรมข้ามชาติ (เข้ากับระบบวิญญาณพอดี)
- ใส่สีสันชีวิตไทยในโลก Hunter: จับใบดำใบแดง, บวช, หวย, TCAS, ญาติถามเรื่องแต่งงาน

## 4. ระบบที่สกัดได้จาก trope (ใช้ร่วมทุกโลก)

| ระบบ | ที่มา | ใช้งาน |
|---|---|---|
| **หน้าต่างระบบ + ภารกิจ** | Hunter, Isekai | ภารกิจพร้อมรางวัลและบทลงโทษ |
| **แรงก์กลาง F → SSS** | ทุกแนว | แต่ละโลกตั้งชื่อขั้นพลังเอง แต่แปลงมาเป็นสเกลเดียวกัน |
| **Death Flag** | Romance fantasy, ผู้อ่านนิยาย | event ที่รู้ล่วงหน้าว่าจะพาไปตาย ต้องหาทางหัก |
| **รายชื่อแค้น (Nemesis)** | Regression, ล้างแค้น | ศัตรูที่จำได้ข้ามชาติ ตามมาทุกชาติ |
| **พบวาสนา** | Murim, Cultivation | การ์ด event หายากที่ให้พลังก้าวกระโดด |
| **ผู้สนับสนุน (Sponsor)** | Apocalypse, Tower | สิ่งมีชีวิตเบื้องบนเลือกสนับสนุน ให้ภารกิจกับรางวัล |
| **ตบหน้า / ชื่อเสียงพลิก** | Cultivation | ยิ่งโดนดูถูกมาก ตอนพลิกยิ่งได้ชื่อเสียงมาก |
| **ทรยศ** | Isekai, Regression | เพื่อนหรือคนรักบางคนมีธงทรยศซ่อนอยู่ ความทรงจำช่วยเปิดเผย |
| **ความรู้อนาคต** | Regression, แชโบล | หุ้น, ที่ตั้ง Gate, ผลการแข่งขัน = ตัวเลือกพิเศษ |
| **อาชีพย้อนเวลา** | Professional regression | เส้นทางอาชีพแบบ BitLife ที่ได้โบนัสจากความทรงจำ |

## 6. การตัดสินใจรอบสุดท้าย (ผู้ใช้มอบให้ตัดสินตามคำแนะนำ)

### 6.1 หน้าจอและธีม

- โครงหน้าจอแบบ BitLife: หัว (ชื่อ/อายุ/แรงก์) → หลอดสเตตัส → บันทึกชีวิต → ปุ่ม **＋ อายุ 1 ปี** → แท็บล่าง `อาชีพ · คน · พลัง · ทำ · วิญญาณ`
- **ธีมเปลี่ยนตามโลก:** Hunter = ดำ/ฟ้านีออน · ยุทธภพ = กระดาษสา/หมึก/ตราแดง · ราชสำนัก = ครีม/ทอง
- **หน้าต่างระบบเป็นสีฟ้าเรืองแสงเหมือนกันทุกโลก** (ของที่ติดตัววิญญาณมา)
- ลูกเล่น: พิมพ์ทีละตัวในฉากสำคัญ, ตัวเลขวิ่งตอนเลเวลอัป, หน้าจอสั่นตอนโดนโจมตี

### 6.2 จังหวะชีวิต (โลก Hunter)

| ช่วงอายุ | จังหวะ |
|---|---|
| 0–5 | ผ่านเร็ว event น้อย (กำหนดครอบครัว, ปมวัยเด็ก) |
| 6–17 | วัยเรียน: เกรด, เพื่อน, แกล้ง/โดนแกล้ง, ชมรม |
| 18–20 | **ตอนพิเศษ: วันตื่นพลัง** · TCAS · จับใบดำใบแดง |
| 20+ | อาชีพ (ทั่วไป หรือ Hunter), Gate, กิลด์, ความรัก, ครอบครัว |
| แก่ | สุขภาพลด, มรดก, ตาย |

### 6.3 ตอนพิเศษ (Episode)

- 3–8 ฉาก แต่ละฉากมี 2–4 ตัวเลือก
- ตัวเลือกที่เช็กสเตตัสต้องแสดง **% สำเร็จ** ก่อนเลือก
- ตัวเลือกจาก**ความทรงจำ**หรือ**พรสวรรค์**เป็นสีพิเศษ
- ฉากที่ตายได้ต้องขึ้น `[คำเตือน: อัตรารอดชีวิต X%]`

### 6.4 กฎการย้อนเวลา

- **Seed ของโลกคงที่ต่อเส้นเวลา:** ย้อนกลับไปแล้ว event เดิมจะเกิดซ้ำที่เดิม เวลาเดิม → ความทรงจำมีค่าจริง
- **ค่าความเบี่ยงเบน (Divergence):** ทุกครั้งที่ทำต่างจากชาติก่อน ค่าจะเพิ่ม เหตุการณ์ที่จำไว้จะมีโอกาสเปลี่ยนตามค่านี้
- ย้อนได้ไม่จำกัด แต่จุดที่ย้อนกลับไปได้จะ**ช้าลงเรื่อยๆ** (ครั้งแรกกลับไปอายุ 15 → ครั้งต่อไปไม่ต่ำกว่าอายุตอนที่ย้อนครั้งก่อน) และค่าความเบี่ยงเบนสูงจะปลุก**เหตุการณ์วิกฤต**ของโลก
- ชาติที่ย้อนเวลาจะได้แต้มวิญญาณน้อยลง (กันการฟาร์ม)

### 6.6 รูปแบบ event (ร่าง)

```ts
{
  id: "hunter.awakening.basic",
  world: "hunter",
  age: [18, 20],
  weight: 10,
  when: { flags: { notAwakened: true } },
  text: "event.hunter.awakening.text",
  choices: [
    { text: "...", check: { stat: "luck", dc: 50 },
      success: { rank: "+1", flag: "awakened" },
      fail:    { health: -20 } }
  ]
}
```

> **หมายเหตุ M1:** event เขียนเป็นออบเจกต์ TypeScript ที่มีฟังก์ชันเงื่อนไข/ผลลัพธ์ และข้อความไทยฝังตรงๆ (ยังไม่ผ่าน key แปลภาษา) เพื่อให้เขียนเนื้อหาได้เร็ว ถ้าจะทำหลายภาษาค่อยแยกข้อความออกภายหลัง

### 6.7 ระบบพลัง (M2)

- **ตื่นพลัง:** ตอนพิเศษบังคับที่อายุ 18–20 (สุ่มตอนเกิด) · ไม่ตื่น ~30% · มีพรสวรรค์สายพลังตื่นแน่นอน · ตื่นช่วงหลัง/ดันเจี้ยนคู่ (คนแบกของ) เป็นทางรอดของคนธรรมดา
- **แรงก์ F→SSS:** SSS ได้จากการเติบโตเท่านั้น · เลื่อนแรงก์ได้จาก: ทะลวงขีดจำกัด (ทุก 15 เลเวล 12%), ตรวจวัดใหม่, ดันเจี้ยนลับ, ผู้ใช้ระบบ/ผู้ตื่นช้า (ทุก 10 เลเวล)
- **สายอาชีพ:** นักดาบ, นักเวท, ฮีลเลอร์, นักลอบสังหาร, แทงก์, ผู้อัญเชิญ (หายาก) — ระบบเสนอ 2–3 สายตามสเตตัสเด่น
- **พลังต่อสู้** = แรงก์×12 + เลเวล×0.8 + สเตตัสหลัก×0.15 + สกิล×2 + โบนัสสาย/กิลด์/ไอเทม · Gate แรงก์ r มีพลัง r×12+10
- **บุก Gate:** ต้องลงทะเบียนเป็น Hunter · ปีละ 3 ครั้ง · เข้าได้สูงกว่าแรงก์ตัวเองไม่เกิน 1 ขั้น · 3 ฉาก (ทางเข้า → เหตุการณ์กลางทาง → บอส) แสดง % ชนะและ % รอด
- **กิลด์:** 5 กิลด์ (ข้าวมันไก่ → ราชสีห์ทองคำ) เพิ่มรายได้/ความปลอดภัย · กิลด์เงาจันทร์จ่ายดีแต่มีงานสกปรก
- **พรสวรรค์สายพลัง** (ช่องลับเท่านั้น): หัวใจมานา, ผู้ตื่นช้า, สายเลือดมังกร, ร่างกายต้องคำสาป, หน้าต่างระบบส่วนตัว
- **อาชีพโลก Hunter:** Hunter, คนแบกของในดันเจี้ยน (เฉพาะคนธรรมดา), เจ้าหน้าที่สมาคม, นักวิจัยคริสตัลมานา

### 6.8 ระบบวิญญาณ (M3)

- **แต้มวิญญาณ** = อายุ/4 + ชื่อเสียง/5 + 1.5·log10(ทรัพย์สิน) + (แรงก์+1)·4 + ลูก·2 + แต่งงาน 4 · ย้อนเวลาได้แต้มพื้นฐานครึ่งเดียว · ความสำเร็จ 17 อย่างให้แต้มครั้งเดียว
- **ร้านวิญญาณ:** พรแห่งโชค 25 · สุ่มเกิดใหม่ 15 · ผนึกพรสวรรค์ 40 · ความทรงจำแจ่มชัด 120 (ถาวร)
- **ย้อนเวลา:** กลับไปอายุ 15 + 3×(จำนวนครั้งที่ย้อนแล้ว) จาก snapshot รายปีใน IndexedDB (ไม่มี snapshot → กลับไปเกิดใหม่ด้วย seed เดิม) · ความเบี่ยงเบน +12 ต่อครั้ง (+6 ถ้ามีความทรงจำแจ่มชัด) · ใช้ความทรงจำครั้งละ +8–15 · โอกาสที่ความทรงจำยังจริง = 1 − ความเบี่ยงเบน/150 (ต่ำสุด 15%)
- **ข้อเท็จจริงของโลก** (คำนวณจาก seed ของโลก + ปีเกิด ไม่ขึ้นกับผู้เล่น): เลขหวยงวดใหญ่, หุ้น MANATECH ×30, มหันตภัยกรุงเทพฯ (Gate แรงก์ S), ดันเจี้ยนลับที่บางนา · คนทรยศจำได้ข้ามชาติ · ลางมรณะเตือนก่อนตายหนึ่งปี
- **เกิดใหม่ยุคถัดไป:** โลกเดิม 15–45 ปีหลังตาย · 30% เกิดเป็นทายาทในตระกูลตัวเอง · event มรดก: คาบประวัติศาสตร์, เจอเหลน, รูปปั้น, หลุมศพตัวเอง, ขุดสมบัติที่ฝังไว้
- **ย้ายเครื่อง:** QR (ลิงก์ `#import=` เปิดด้วยกล้องมือถือ, ย่อบันทึกให้พอดี QR) · คัดลอกรหัส · ไฟล์ .txt
- **PWA:** manifest + ไอคอนที่สร้างจากสคริปต์ + service worker (HTML ลองเน็ตก่อน, ไฟล์อื่นใช้แคช)

### 6.9 โลกยุทธภพ (M4)

- **โครงหลายโลก:** `content/worlds.ts` เก็บชื่อ สกุลเงิน (ยุทธภพแสดงเป็นตำลึง = เงินในเกม/1000) บ้านเกิด อาชีพพ่อแม่ สาเหตุการตาย อายุตื่นพลัง คำเรียกใน UI · event/อาชีพ/กิจกรรมผูกกับโลก · ธีมสลับด้วย `html[data-world]`
- **ปลดล็อก:** ชาติแรกเป็นโลก Hunter · "เส้นเวลาใหม่" สุ่มระหว่าง Hunter กับยุทธภพ · Admin เลือกโลกได้
- **ขั้นยุทธ์ 9 ขั้น:** ผู้ฝึกหัด → ชั้นสาม → ชั้นสอง → ชั้นหนึ่ง → ยอดฝีมือ → ปรมาจารย์ → ยอดยุทธ์ → เหนือธรรมชาติ → เซียน (ใช้ระบบแรงก์เดียวกับ Hunter)
- **คัดเลือกศิษย์** อายุ 12–14 แทนวันตื่นพลัง → เลือกสำนัก → เลือกวิชา (กระบี่ ฝ่ามือ ทวน อาวุธลับ แพทย์ยุทธ์ วิชามาร)
- **ทะลวงขั้น:** ไม่มีการเลื่อนขั้นอัตโนมัติ — ถึงเลเวล (ขั้น+1)×8+ขั้น² แล้วเกิดตอนพิเศษ: ฝืนทะลวง (เสี่ยงธาตุไฟเข้าแทรก) / ใช้ยาเม็ด / รอ · ขั้นสุดท้ายคือทัณฑ์สวรรค์ · เซียนอายุ 50+ เลือกเหาะขึ้นสวรรค์ได้
- **สำนัก 6 แห่ง:** พรรคกระยาจก, สำนักกระบี่เมฆา, ตระกูลถังเรือนพิษ, วัดวัชระ, ลัทธิมารสวรรค์ (ฝ่ามาร), พันธมิตรยุทธจักร
- **ภารกิจยุทธภพ** แทนการบุก Gate: ปราบโจร คุ้มกันขบวน ล่าสัตว์อสูร ตามล่าโจรเด็ดดอกไม้ บุกรังลัทธิมาร · มีถ้ำรอยกระบี่ลับ
- **Trope:** ตบหน้าศิษย์ใน, ถอนหมั้น "สามสิบปีฝั่งตะวันออก" แล้วตบหน้าคืน, ตกหน้าผาพบวาสนา, วิญญาณผู้เฒ่าในแหวน, ขอทานสอนวิชา, ครอบครัวถูกสังหาร → ชำระแค้น, ชุมนุมประลองยุทธ์, ฝ่ายธรรมะตามล่าสาวกมาร, สอบจอหงวน (คนธรรมดา), แม่สื่อ
- **ความทรงจำยุทธภพ:** ถ้ำหลังน้ำตกเจ็ดชั้น, ลัทธิมารบุกที่ราบภาคกลาง, ลางมรณะ · มรดก: หอบรรพชน, ทายาทตกอับ

### 6.10 โลกราชสำนัก (M5)

- **ธีม:** ครีม/ทอง กรอบการ์ดซ้อนสองชั้น ฟอนต์ serif · สกุลเงิน "เหรียญทอง" (= เงินในเกม/10,000) · ปีจักรวรรดิ 812
- **นิยายต้นฉบับ "ดอกกุหลาบแห่งจักรวรรดิ":** อายุ 7 ปีความทรงจำโลกเก่ากลับมา แล้วรู้บทบาทของตัวเอง — **ตัวร้าย** (ตระกูลดยุก/เคานต์เสมอ, บารอน 40%) · **ตัวเอก** (สามัญชน 30%) · **ตัวประกอบ**
- **Death Flag ของตัวร้าย:** อายุ 12 พบตัวเอก · 16 งานเปิดตัวสังคม · 18 คดีวางยาพิษ → อายุ 20 ถ้าหักได้ ≥2 หรือหนีออกเมืองหลวงได้ = รอด (ความสำเร็จ "หักชะตาตัวร้าย") ไม่งั้นขึ้นลานประหาร (ยังมีทางรอดจากความเมตตาหรือแหกลานด้วยเวท)
- **ตัวเอก:** อายุ 15 ตื่นพลังศักดิ์สิทธิ์เป็นผู้สมัครนักบุญ · ถูกตัวร้ายกลั่นแกล้ง · **ตัวประกอบ:** อายุ 17 เทศกาลดอกไม้ที่ตัวประกอบทั้งเมืองตาย
- **พลังเวท:** พิธีตรวจพลังที่วิหารตอนอายุ 10 · วงเวท ไร้วง → วงที่ 8 · 6 สาย: ไฟ, น้ำแข็ง, ศักดิ์สิทธิ์, ดาบออร่า, ผู้ทำสัญญาภูต, เวทมืด (ถูกวิหารล่าแม่มด) · 6 สังกัด
- **ภารกิจราชสำนัก:** มอนสเตอร์ชายแดนเหนือ, คดีวางยาพิษ, คุ้มกันองค์หญิง, ปิดประตูมิติปีศาจ, ล่าแม่มด · มีวงเวทโบราณลับ
- **Trope:** พ่อเย็นชา, น้องบุญธรรม, ลูกนอกสมรสของเคานต์, สถาบันจักรวรรดิ + ทุนสามัญชน, ราชวงศ์หันมาสนใจตัวร้าย → ขอแต่งงาน → สวมมงกุฎ, สัญญาแต่งงานหนึ่งปีกับดยุกแห่งทิศเหนือ, จักรพรรดิทรราช, เปิดร้านขนม/ออกแบบชุดด้วยความรู้โลกเก่า
- **ความทรงจำ:** กบฏแย่งชิงบัลลังก์ (คืนเดือนดับ), โรคระบาดดอกไม้ดำ (กว้านซื้อหญ้าจันทร์เงิน), ลางมรณะ · มรดก: ภาพวาดในหอภาพ, ไถ่ถอนคฤหาสน์ตระกูล
- **ความสำเร็จใหม่:** หักชะตาตัวร้าย, สวมมงกุฎ, นักบุญแห่งยุค, ตัวประกอบผู้เปลี่ยนบท (+ เซียนเหาะ, ยอดฝีมือแห่งยุค จากยุทธภพ)

- **ปาร์ตี้** (relation `ally`, นับได้สูงสุด 3 คน; คนละ CP +2 และรอด +3%) — event: ชวนเข้าทีม, รอบกองไฟ, รักในทีม, เสียสละ (ตายได้), ทรยศ (ความผูกพัน < 30), เติบโต
- **ฉายา** 17 แบบจากสถานะ/เหตุการณ์ (ผู้ย้อนเวลา, ผู้มาทีหลัง, ผู้ถูกเลือก, ผู้รอดจากเกตแดง ฯลฯ) — ได้แล้วติดตัวอัตโนมัติถ้ายังไม่มี เปลี่ยนได้ที่แท็บพลัง · ใส่ได้ 1 อัน โบนัสเล็กน้อย (CP/รอด/EXP/เงิน/ความสุข)

### 6.20 เล่นอิสระ (M14, สร้างแล้ว)

- **เลือกโลกตอนเริ่มเกม** — หน้าแรกมีการ์ด 6 โลก + 🎲 สุ่มโลก · ปุ่ม "ทิ้งชีวิตนี้แล้วเกิดใหม่" กลับมาหน้าเลือกโลก
- **เล่นต่อเป็นลูก** (หน้าจอตาย): ภาคต่อของเรื่องเดิม — ชื่อเรื่องเดิม + "ภาค N", เริ่มที่อายุปัจจุบันของลูก, มรดกแบ่งเท่ากันระหว่างพี่น้อง, ชื่อเสียงตระกูล 30%, พ่อ/แม่ที่ตายคือตัวคุณชาติก่อน, ชะตาที่เลยวัยแล้วเลื่อนมาปีหน้า, โลกที่พังแล้วยังพังอยู่ (ลูกได้ระบบทันที) · ย้อนเวลาได้ไม่เกินวันที่เริ่มเล่นรุ่นนั้น
- **สกิลตามแท็ก**: สกิลมีแท็ก (ต่อสู้/หลบหนี/ช่วยชีวิต/การแพทย์/เข้าสังคม/การแสดง/ลอบเร้น/เกม/ทำอาหาร/ธุรกิจ/การเรียน) · ฉากประกาศแท็กเอง (ไม่ประกาศ + เสี่ยงตายมี % = ต่อสู้) — สกิลรักษาไม่ขึ้นตอนดวล สกิลร้องเพลงขึ้นตอนออดิชัน
- **สกิลติดตัว 16 แบบ** ทุกโลก ไม่ต้องมีพลัง: ได้จากการฝึก อ่าน ทำบุญ เที่ยว รอดจากพิษ/ใกล้ตาย ล้มบอส ชื่อเสียง ความรวย ฯลฯ · ผลเป็นโบนัสการเช็ก/พลังต่อสู้/รอด/EXP/รายได้/สุขภาพหรือความสุขรายปี · แท็บพลังบอกวิธีปลดล็อก
- **สมดุล**: วันสิ้นโลก — ตายคืนแรก 15% → 8%, ร่างกายผู้มีระบบฟื้นตัวทุกปี (มีกลุ่ม +4) · โลกธรรมดา — ได้ระบบ/เลื่อนระดับไม่ทำให้ดัง (ไม่มีใครเห็นระบบ), ภารกิจประจำไม่เพิ่มชื่อเสียง

### 6.23 ยุทธภพ (M17)

กลไกประจำโลกยุทธภพ — สถานะทั้งหมดเก็บใน `life.flags` (ไม่แตะ `engine/types.ts`) · โค้ดหลัก `content/murim/m17core.ts` · การ์ดในแท็บพลัง `ui/tabs/MurimCard.tsx`

- **📜 ทำเนียบยอดฝีมือ (สิบอันดับ)** — NPC สิบคน มีชื่อ ฉายา อายุ และพลังฝีมือ (เทียบกับพลังต่อสู้ของผู้เล่น)
  - ทุกปี: ยอดฝีมืออายุมากขึ้น ฝีมือขึ้น/ลงตามวัย · ตาย (เพิ่มขึ้นหลัง 68 ปี) หรือเกษียณ (หลัง 62 ปี) แล้วมีคนหน้าใหม่ขึ้นมาแทน · NPC จัดลำดับกันเองตามฝีมือ แต่ช่องของผู้เล่นขยับได้ด้วยการประลองเท่านั้น (ยกเว้นฝีมือตกจนคนข้างล่างทิ้งห่าง)
  - ประกาศหอบันทึกยุทธภพทุกปีที่มีข่าว (ตาย/เกษียณ/ถูกแซง) และทุก 4 ปีสำหรับผู้ฝึกยุทธ์ขั้นชั้นหนึ่งขึ้นไป
  - เข้าทำเนียบ: ถึงขั้นยอดฝีมือแล้วท้าประลองคนที่อยู่เหนือหนึ่งอันดับ (ยังไม่ติด = อันดับ 10) — ท้าเปิดเผย (เสี่ยงตาย) / แตะแล้วหยุด (ไม่ตายแต่ยากกว่า) / วางยา (ง่ายขึ้น แต่มาร −15 และได้ศัตรู) · ถูกท้าป้องกันอันดับ · แพ้ = ตกอันดับ · ติดสินบนหอบันทึก · ส่งต่อตำแหน่งตอนแก่
  - ติดทำเนียบได้ EXP ทุกปีจากการถูกท้าไม่หยุด · ฉายา "หนึ่งในสิบยอดฝีมือ" (+2 พลังต่อสู้) และ "อันดับหนึ่งใต้หล้า" (+4)
- **☯️ มาตรธรรมะ/มาร** −100…+100 — ขยับจากทางเลือกเกือบทุก event ใหม่ · ค่าเริ่มต้นตามวิชา/สำนัก (วิชามาร −20, ลัทธิมาร −15, วัดวัชระ/สำนักกระบี่เมฆา +10) · ลัทธิมารดึงลง/วัดวัชระดึงขึ้นทีละนิดทุกปี
  - ≤ −40: กองล่ามารของพันธมิตรยุทธจักรตามล่า (ถี่ขึ้นยิ่งมืด) · สำนักฝ่ายธรรมะขับออก · พระธุดงค์ให้โอกาสกลับตัว
  - ≤ −30: ลัทธิมารชักชวน · ≤ −50 + ขั้นยอดยุทธ์: ตำแหน่งทูตซ้าย · ≤ −60: ศาลยุทธภพ, ชื่อที่ใช้ขู่เด็ก
  - ≥ 40 + ขั้นปรมาจารย์: เก้าอี้ผู้อาวุโสพันธมิตรยุทธจักร · ≥ 30: คุ้มกันพระธาตุ · ≥ 60: ศาลเจ้าของคนเป็น · ช่วงกลาง (|ค่า| < 20): ทั้งสองฝ่ายมาขอให้เลือกข้าง
  - ฉายา "ผู้ทรงธรรมแห่งยุทธภพ" (≥ 70, รอด +4%) / "จอมมารเขย่าใต้หล้า" (≤ −70, พลังต่อสู้ +3)
- **📖 สมุดบุญคุณ/ความแค้น** — บันทึกชื่อคน + เหตุผล + อายุที่เกิด: 📗 เขาติดหนี้บุญคุณเรา / 📕 เราทำร้ายเขาไว้
  - event "หว่านเมล็ด" สร้างรายการ (ช่วยคนจมน้ำ ไถ่ตัวเด็ก ให้ยืมเงินบัณฑิต / โกงเต๋า ยึดวัวแม่ม่าย ทำลายตันเถียน ฯลฯ)
  - event "เก็บเกี่ยว" ดึงรายการที่ค้างนานที่สุดกลับมา: ลูกหนี้มาช่วยตอนถูกซุ่ม ส่งของขวัญ เตือนนักฆ่า กลายเป็นขุนนางผู้ตัดสินคดี ขอความช่วยเหลือกลับ หรือทรยศ · ฝ่ายแค้นส่งมือสังหาร วางยา ปล่อยข่าว ลักพาคนในครอบครัว และ **ลูกหลานตระกูลที่ล่มสลาย** กลับมาหลัง 12 ปี · ตอนแก่ คนเคยแค้นมาขอคืนดี
  - ชำระแล้วเก็บเป็นประวัติ · ชำระบุญคุณครบ 3 = ฉายา "ผู้หว่านเมล็ดบุญ"
- **🏯 ก่อตั้งสำนัก** — ขั้นปรมาจารย์ + อายุ 28 + เงินสร้างสำนัก: ตั้งชื่อเองในแท็บพลัง หรือเลือกจาก 3 ชื่อใน event

### 6.24 ราชสำนัก (M18)

เอกลักษณ์ของโลกราชสำนัก = **การเมือง** — ทุกการตัดสินใจคือการเลือกข้าง (ระบบอยู่ใน `content/court/politics.ts` · เก็บใน `life.flags` ทั้งหมด)

- **สามขั้วอำนาจ** 👑 ราชวงศ์ · ⛪ วิหาร · 🎩 สภาขุนนาง
  - ท่าทีต่อผู้เล่นแต่ละขั้ว −100…+100 (`fac_*`) — เริ่มตามฐานะครอบครัวตอนอายุ 6 · ค่าที่สูง/ต่ำมากค่อยๆ ถอยหาศูนย์ถ้าไม่รักษา
  - ดุลอำนาจรวม 100% (`pow_*`, ขั้วละอย่างน้อย 5%) ขยับทุกปีตั้งแต่ 12 ปี · ขั้วที่ผู้เล่นหนุนได้แรงส่ง · เปลี่ยนขั้วที่เป็นใหญ่จะขึ้นข่าวในบันทึก
  - ผล: ขั้วของคุณขึ้นเป็นใหญ่ → ได้ตำแหน่ง/ล้างแค้น · ขั้วของคุณล่ม → ภักดีต่อหรือเปลี่ยนข้าง · เป็นศัตรูกับขั้วที่กุมอำนาจ (≤ −45 และอำนาจ ≥ 40%) → กวาดล้างของวังหลวง / ศาลไต่สวนศรัทธา / นักฆ่าของสภา (ตายได้) · ทั้งสามขั้วไว้ใจ (≥ 25) → ร่างกฎบัตรสามเสา
  - **Death Flag**: ราชวงศ์โปรดปราน ≥ 40 หักธงตั้งแต่วัยรุ่น · ≥ 30 ขอไต่สวนคดีวางยาใหม่ (DF3) · ≥ 50 อภัยโทษบนลานประหาร · วิหาร ≥ 35 ส่งพยาน / ≥ 50 ให้ที่พักพิง · สภาขุนนาง ≥ 35 ลงนามยืนยัน (แล้วมาทวงหนี้ทีหลัง) · ความโปรดปรานราชวงศ์เพิ่มโอกาสขอความเมตตา
- **ความนิยมในสังคม** 0–100 (`soc`) — งานน้ำชา งานเต้นรำ ซาลอน แฟชั่น · ต่ำมาก = ถูกสังคมขับไล่ · สูงมาก = ราชินีแห่งวงสังคม / เปิดซาลอนของตัวเอง
- **ข่าวลือ** (`rumors` JSON, สูงสุด 6 เรื่อง) — ข่าวลือเกี่ยวกับคุณ/คนอื่น ดี/ร้าย ความร้อนแรง 🔥1–5 ลดปีละ 1 · ข่าวที่ยังลอยอยู่ปรับความนิยมทุกปี · ปล่อย ปฏิเสธ กลบด้วยข่าวใหม่ หรือขอใบรับรองจากวิหาร
- **แผนการ** (ปุ่มในการ์ด อายุ 15+ ปีละครั้ง): 🍷 ข่าวลือยาพิษ · 💌 แม่สื่อ · 🕯️ เปิดโปงคู่แข่ง (เลือกเวที: จักรพรรดิ/สังฆราช/สภา/กลางงานเลี้ยง) · 🤝 สร้างพันธมิตร · 🎻 เปิดซาลอน — ทุกแผนมี 2–3 ฉากและย้อนเข้าตัวได้ · ทำบ่อยจะเจอคู่ปรับเอาคืน คนรับใช้ขายข้อมูล บททดสอบพันธมิตร และฉายา "แมงมุมแห่งราชสำนัก"
- **คู่ปรับประจำชีวิต** ชื่อคงที่ตาม seed (เช่น เลดี้โรซาลีน เดอ มาร์โกต์) โผล่ตั้งแต่งานน้ำชาแรกจนงานน้ำชาสุดท้ายตอนแก่

- **UI**: การ์ด ⚖️ การเมืองในราชสำนัก ในแท็บพลัง — แถบดุลอำนาจ มาตรท่าทีสามขั้ว ความนิยม ข่าวลือ และปุ่มแผนการ

### 6.26 วันสิ้นโลก (M20)

- **นโยบาย**: ปันส่วน (อิ่ม/ปกติ/เข้มงวด) · ผู้ลี้ภัย (เปิด/คัดกรอง/ปิด) · บทลงโทษ (ให้อภัย/แรงงาน/เนรเทศ) · ปุ่ม **ออกสำรวจ** (ปีละครั้ง ต่อสู้ได้ของ 4 แหล่ง + เหตุการณ์กลางทาง) · **แลกของ/ทำพันธมิตร** กับฐานอื่น (พ่อค้าในฐานให้เรตดีขึ้น)

- **พรสวรรค์ +103** (`content/talentsMore.ts`, รวม 123): ธรรมดา 38 · หายาก 33 · ตำนาน 18 · ศักดิ์สิทธิ์ 7 · **หนึ่งเดียวในโลก 7** — ผลเขียนเป็นข้อมูล (ค่าสถานะตอนเปิดเผย · ค่าสถานะต่อปี · โบนัสการเช็ก · โอกาสรอด · พลังต่อสู้ · EXP · รายได้ · แรงก์ตอนตื่นพลัง) และคำอธิบายสร้างจากผลจริง
  - สายพลังใหม่ 10 อัน (ช่องลับเท่านั้น) แรงก์ตอนตื่น +1…+4
  - **หนึ่งเดียวในโลก**: ช่องที่เห็น 0.02%/ช่อง · ช่องลับ 0.08% · พรแห่งโชคเพิ่มเป็น 0.1%/0.3% → ราว 1 ใน 1,000 ชีวิต (ไม่ใช่ศูนย์) · ขอบรุ้งเคลื่อนไหว · ความสำเร็จลับ "หนึ่งเดียวในโลก" 100 แต้ม
- **สกิลติดตัว +107** (`content/passivesMore.ts`, รวม 123): ได้จากวิธีใช้ชีวิต — ร่างกาย จิตใจ ทักษะ (คอร์ส/ผลงาน) สังคม เงิน ด้านมืด (คุก/อาชญากรรม) การเดินทาง ของสะสม ภารกิจ พลัง และประจำแต่ละโลก
  - **เพดานผลรวมของสกิลติดตัว**: เช็กค่าสถานะ +15%/ค่า · โอกาสรอด +12% · พลังต่อสู้ +15 · EXP/รายได้ +30% · ค่าสถานะรายปี +3/ค่า (พรสวรรค์ไม่นับในเพดาน)
  - แท็บพลัง: กล่องสกิลติดตัวพับเก็บได้ — ที่มีเป็นชิปกดดูผล ที่ยังไม่ได้พับไว้อีกชั้น
- **สมุดพรสวรรค์** (แท็บวิญญาณ): บันทึกพรสวรรค์ที่เคยได้ทุกชาติ แยกตามระดับ · หน้าจอตายแสดงจำนวนสกิลติดตัวและของสะสมที่เจอในชาตินั้น

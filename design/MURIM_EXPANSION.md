# 0. เป้าหมายและวิธีใช้เอกสาร

เอกสารนี้ต่อยอดจากแผน Murim World ซึ่งผสมการจำลองชีวิตรายปี การเติบโตในยุทธภพ
ความสัมพันธ์ระหว่างตัวละคร การเมืองระหว่างสำนัก และการเล่นข้ามรุ่น
เป้าหมายคือเพิ่มความลึกให้ระบบเดิม โดยเน้น **การเชื่อมโยงของระบบและผลที่ผู้เล่นสัมผัสได้**
มากกว่าการเพิ่มเมนูหรือค่าสถานะจำนวนมาก

ไม่มีใครรับประกันคะแนน 10/10 จากผู้เล่นทุกคนได้
แต่สามารถมุ่งสู่คุณภาพระดับสูงด้วยต้นแบบที่เล่นได้ การทดสอบอัตโนมัติ การทดสอบสมดุล
และการเล่นกับผู้ใช้จริง

## ผลลัพธ์ที่ต้องการ

1.  โลกดำเนินต่อได้ แม้ผู้เล่นไม่เข้าไปแทรกแซงทุกเหตุการณ์
2.  NPC มีเป้าหมาย บุคลิก ความทรงจำ ความสัมพันธ์ ทรัพยากร
    และข้อจำกัดที่อธิบายการกระทำได้
3.  การตัดสินใจมีผลทันที ระยะยาว และอาจย้อนกลับมาในรุ่นลูกหลาน
4.  ความพ่ายแพ้และบาดแผลเปิดทางเลือกใหม่ ไม่ทำให้เกมตันอย่างไร้เหตุผล
5.  การเติบโตด้านยุทธ์ช้า มีความหมาย และยอดฝีมือระดับสูงหายากจริง
6.  การเล่นแต่ละรอบแตกต่างจากภูมิหลัง บุคลิก เป้าหมาย เหตุการณ์โลก
    และการเลือกของผู้เล่น
7.  ระบบมีความสอดคล้อง ตรวจสอบ และทดสอบได้
8.  UI อธิบายความเสี่ยงโดยไม่เปิดเผยความลับทุกอย่าง
9.  Save/load และการเปลี่ยนรุ่นไม่ทำให้ประวัติศาสตร์เสียหาย
10. เนื้อหาจำนวนมากมีคุณภาพและความเชื่อมโยง ไม่ใช่เหตุการณ์ซ้ำที่เปลี่ยนแค่ชื่อ

# 1. เสาหลักการออกแบบ

## 1.1 ชีวิตหนึ่งชีวิตต้องมีเรื่องราว

ผู้เล่นไม่ควรรู้สึกว่ากดเพิ่มอายุเพื่อเก็บตัวเลขเท่านั้น ทุกปีควรมีอย่างน้อยหนึ่งสิ่งให้ตัดสินใจ เช่น
เป้าหมายชีวิต ความสัมพันธ์ โอกาสเสี่ยง การเปลี่ยนแปลงของโลก หรือการพักฟื้นที่มีผลจริง
ไม่จำเป็นต้องมีฉากใหญ่ทุกปี เพราะจะทำให้ผู้เล่นเหนื่อยและเหตุการณ์สำคัญหมดความพิเศษ

## 1.2 ทุกการเลือกมีต้นทุน

ฝึกหนักโตเร็วแต่เสี่ยงบาดเจ็บ ช่วยเพื่อนเสียเงินแต่สร้างความภักดี
รับตำแหน่งราชสำนักได้อำนาจแต่ต้องเชื่อฟังคำสั่ง
เปิดเผยตำราทำให้สำนักรุ่งเรืองแต่ศัตรูอาจเรียนรู้วิชา
เลือกทายาทที่เก่งอาจทำให้ลูกคนอื่นรู้สึกถูกทอดทิ้ง
ล้างแค้นอาจสะใจแต่ทำลายความสัมพันธ์และดึงครอบครัวเข้าสู่วงจรสงคราม

หลีกเลี่ยงตัวเลือกที่มีคำตอบดีที่สุดเสมอ
ทางเลือกแต่ละแบบควรเหมาะกับค่านิยมและเป้าหมายที่แตกต่างกัน

## 1.3 สมจริงแบบเกม ไม่ใช่จำลองทุกอย่างจนช้า

จำลองอย่างละเอียดกับ NPC และเหตุการณ์ที่เกี่ยวข้องกับผู้เล่น
ส่วนประชากรทั่วไปใช้ข้อมูลย่อหรือการจำลองเป็นกลุ่มได้ หากผลยังน่าเชื่อถือและโลกไม่ขัดแย้งกัน

## 1.4 ความตายมีความหมาย

\[ฐานเดิม\] ตัวละครอาจตายจากการต่อสู้ พิษ โรค การประหาร หรืออายุขัย และเล่นต่อเป็นลูก
ศิษย์ หรือคนใหม่ในโลกเดิมได้

\[ข้อเสนอใหม่\] หากเหมาะสม ก่อนตายให้มีโอกาสส่งต่อวิชา เขียนคำสั่งเสีย จัดการมรดก คืนดี
หรือเปิดเผยความลับ แต่ห้ามบังคับฉากลาในกรณีตายกะทันหันจากการตัดสินใจเสี่ยง

# 2. ระบบเป้าหมายชีวิตและแรงจูงใจ

**ความสำคัญ: สูงสุด** --- ควรเป็นแกนกลางที่เชื่อมกิจกรรม เหตุการณ์ NPC และตอนจบ

\[ข้อเสนอใหม่\] ผู้เล่นและ NPC ควรมีเป้าหมายหลักหนึ่งข้อ เป้าหมายรองได้ไม่เกินสองข้อ
พร้อมความกลัว ค่านิยม และข้อจำกัด เป้าหมายไม่ใช่เพียง achievement
แต่เป็นแรงผลักดันให้เลือกกิจกรรมและเปลี่ยนพฤติกรรม

## 2.1 ประเภทเป้าหมาย

-   ล้างแค้นผู้ทำลายครอบครัว
-   ปกป้องคนรักหรือครอบครัว
-   กอบกู้หรือก่อตั้งสำนัก
-   บรรลุระดับพลังสูงสุด
-   สร้างความมั่งคั่งและอิสรภาพ
-   ไต่เต้าในราชสำนัก
-   เป็นแพทย์ ช่างตีอาวุธ หรือพ่อค้าที่มีชื่อเสียง
-   ค้นหาความจริงเรื่องชาติกำเนิด
-   รักษาคำสัตย์ต่ออาจารย์หรือพี่น้องร่วมสาบาน
-   ชดใช้บาปหรือเลิกใช้ความรุนแรง
-   สืบทอดความรู้ให้คนรุ่นหลัง
-   ใช้ชีวิตสงบและเลี้ยงดูครอบครัว
-   ขึ้นเป็นฮ่องเต้ มารสวรรค์ หรือผู้นำสำนัก
-   บรรลุเซียนเมื่อเข้าเงื่อนไขปลายเกม

## 2.2 เป้าหมายต้องเปลี่ยนได้อย่างมีเหตุผล

เด็กที่อยากแข็งแกร่งเพื่อปกป้องแม่อาจกลายเป็นแพทย์เมื่อแม่เสียชีวิต
ผู้แก้แค้นอาจให้อภัยเมื่อรู้ความจริง หรือยิ่งโหดเหี้ยมเมื่อพบว่าความจริงซับซ้อน
ผู้ทะเยอทะยานอาจค้นพบว่าการปกครองยากกว่าการยึดอำนาจ เป้าหมายเปลี่ยนจากเหตุการณ์สำคัญ
ไม่ใช่สุ่มเปลี่ยนโดยไร้สาเหตุ

## 2.3 โครงสร้างเป้าหมาย

ทุกเป้าหมายควรมีเงื่อนไขเริ่มต้น ขั้นตอนย่อย ความคืบหน้าที่มองเห็นได้ ความเสี่ยง/ต้นทุน
ผลลัพธ์หลายแบบ และผลต่อความทรงจำ ชื่อเสียง ความสัมพันธ์และ Chronicle

ตัวอย่างเป้าหมาย "ล้างแค้น": ระบุผู้รับผิดชอบจากหลักฐาน → เลือกฝึกฝน สืบสวน
หรือรวบรวมพรรคพวก → เผชิญข้อมูลที่อาจขัดกับความเชื่อเดิม → เลือกแก้แค้น เปิดโปง เจรจา
หรือให้อภัย → ผลส่งต่อไปยังครอบครัวและรุ่นหลัง

**\[เกณฑ์ยอมรับ\]** NPC ที่มีเป้าหมายเหมือนกันอาจเลือกวิธีต่างกันตามบุคลิก
ทรัพยากรและความกลัว ความล้มเหลวต้องส่งผลต่อชีวิต ไม่ถูกลบทิ้ง
และผู้เล่นสามารถสนุกได้โดยไม่เป็นยอดฝีมือ

# 3. วงจรชีวิตรายปีที่ไม่ซ้ำซาก

\[ฐานเดิม\] เกมใช้การเพิ่มอายุรายปี มีกิจกรรมฝึกฝน ยุทธภพ ชีวิต ครอบครัว และอาชญากรรม

\[ข้อเสนอใหม่\] แบ่งปีเป็นการตัดสินใจหลักและกิจกรรมเสริม
เพื่อให้มีโครงสร้างโดยไม่บังคับให้จัดการทุกระบบทุกปี

## 3.1 โครงสร้างหนึ่งปี

1.  สรุปสถานะ: อายุ สุขภาพ เงิน หนี้ บาดแผล ความสัมพันธ์ และเหตุการณ์ค้าง
2.  เลือกแผนหลัก: ฝึกฝน ทำงาน เดินทาง บริหารสำนัก ดูแลครอบครัว หรือสืบสวน
3.  ทำกิจกรรมรองตามเวลาและทรัพยากร
4.  จำลองการกระทำของ NPC เศรษฐกิจและสำนัก
5.  เลือก/แก้เหตุการณ์ประจำปีที่เกิดจากเงื่อนไขจริง
6.  สรุปผล รายได้ การฝึก ความสัมพันธ์ บาดแผล และผลกระทบ
7.  บันทึกเหตุการณ์สำคัญลง Chronicle
8.  เพิ่มอายุและตรวจการเปลี่ยนช่วงชีวิต

บางปีอาจใช้เวลาทั้งหมดไปกับการพักฟื้นหรือวิกฤต ไม่จำเป็นต้องบังคับให้ทำทุกกิจกรรม

## 3.2 การเร่งเวลาอย่างยุติธรรม

มีตัวเลือกเดินปีถัดไป ข้ามสามปี หรือปิดด่านฝึก 1--3 ปี แต่ก่อนข้ามต้องเตือนความเสี่ยงที่รู้ได้
เช่น บาดแผลแย่ลง คนในครอบครัวอาจเสียชีวิต หนี้เพิ่ม หรือสงครามปะทุ
ระหว่างข้ามเวลาให้หยุดเมื่อเกิดเหตุการณ์สำคัญที่ไม่ควรถูกข้ามโดยไม่ตัดสินใจ

## 3.3 จังหวะของปี

สลับปีสงบ ปีที่มีแรงกดดัน ปีพลิกผัน ปีแห่งผลลัพธ์จากอดีต และปีแห่งโอกาสหายาก
อย่าบังคับให้ทุกปีมีดราม่าระดับใหญ่

## 3.4 ลดความเหนื่อยจาก UI

เพิ่มทำซ้ำแผนเดิมสำหรับกิจกรรมเสี่ยงต่ำ สรุปผลแบบย่อ เปิดรายละเอียดได้
ปิดแจ้งเตือนเล็กน้อยได้ และไม่บังคับเปิดหลายหน้าต่างเพื่อทำกิจกรรมพื้นฐาน

# 4. โลกมีชีวิต: NPC อิสระ ความทรงจำ และข่าวสาร

**ความสำคัญ: สูงสุด**

\[ฐานเดิม\] NPC มีบุคลิก อารมณ์ ความทรงจำ ความสนิทและเป้าหมาย สามารถแต่งงาน มีลูก
เลื่อนตำแหน่ง แก้แค้นหรือขอความช่วยเหลือได้

\[ข้อเสนอใหม่\] เพิ่มระบบตัดสินใจที่มีเหตุผลและขอบเขตการรับรู้ เพื่อไม่ให้ NPC
รู้ทุกอย่างโดยไม่มีที่มา

## 4.1 โปรไฟล์ NPC

NPC สำคัญควรมีตัวตนถาวร อายุ สุขภาพ ความสามารถ วิชา อาชีพ ทรัพยากร บุคลิก 2--3
ลักษณะ ค่านิยม ข้อห้าม เป้าหมาย ความกลัว จุดอ่อน ความลับ ความสัมพันธ์ ความทรงจำ
ความเชื่อเกี่ยวกับคนอื่น สถานะชีวิต และตำแหน่ง/ภูมิภาค NPC ทั่วไปใช้โปรไฟล์ย่อได้
แต่ตัวละครสำคัญต้องมีข้อมูลพอให้เรื่องราวต่อเนื่อง

## 4.2 ความทรงจำแบบมีน้ำหนัก

แบ่งเป็นความทรงจำสำคัญ เช่น ช่วยชีวิต ฆ่าคนรัก ทรยศ สาบาน รับเป็นศิษย์ ทำลายสำนัก;
ความทรงจำระยะกลาง เช่น ยืมเงิน ชนะประลอง ช่วยงาน; และเหตุการณ์เล็ก เช่น
บทสนทนาทั่วไป

แต่ละความทรงจำควรเก็บผู้กระทำ ผู้ได้รับผล ปี/สถานที่ สิ่งที่ NPC รู้จริง การตีความ อารมณ์
ความสำคัญ การเปิดเผยต่อสังคม และผลต่อความสัมพันธ์/เป้าหมาย NPC
สองคนอาจตีความเหตุการณ์เดียวกันต่างกัน เช่น ผู้เล่นมองว่าการไว้ชีวิตคือเมตตา
แต่ศัตรูมองว่าเป็นการดูหมิ่น

## 4.3 ขอบเขตความรู้และข่าวสาร

ผู้เห็นเหตุการณ์รู้จากการเห็น คนในสำนักรู้ผ่านรายงาน ข่าวข้ามภูมิภาคแพร่ช้าหรือบิดเบือน
ข่าวสำคัญแพร่เร็วขึ้นเมื่อมีพยานหรือผู้เล่าชื่อดัง การปกปิดตัวตน เอกสารปลอม
และการกำจัดหลักฐานลดโอกาสเปิดเผยได้

ข่าวมีระดับ: ยืนยันจากหลักฐาน, มีพยานหลายคน, แหล่งข่าวเดียว, บิดเบือน,
หรือจงใจปล่อยข่าวปลอม ข่าวควรมีแหล่งที่มา เวลาที่เกิด/ได้รับ ความน่าเชื่อถือ
และแรงจูงใจของผู้ปล่อยข่าว

## 4.4 การตัดสินใจของ NPC

ประเมินเป้าหมาย บุคลิก ความสัมพันธ์ ทรัพยากร ความเสี่ยง ข้อมูลที่มี
หน้าที่ต่อครอบครัว/สำนัก/ราชสำนัก และวิกฤตปัจจุบัน ใช้กฎหรือคะแนนที่ตรวจสอบได้
สุ่มเล็กน้อยเพื่อความหลากหลาย แต่ห้ามสุ่มจนไร้เหตุผล

## 4.5 วงจรชีวิต NPC

NPC อาจฝึก เปลี่ยนอาชีพ แต่งงาน มีลูก สร้างพันธมิตร เปลี่ยนฝ่าย บาดเจ็บ ถูกจับ เสียชีวิต
เลื่อนตำแหน่ง ย้ายภูมิภาค หรือเปลี่ยนเป้าหมาย ทั้งหมดต้องมีข้อจำกัดด้านอายุ สุขภาพ เงิน
ความสามารถและสถานการณ์

**\[เกณฑ์ยอมรับ\]** NPC ไม่แก้แค้นเรื่องที่ไม่มีทางรู้
คนตายไม่กลับมาทำกิจกรรมโดยไม่มีเหตุการณ์รองรับ NPC
สำคัญดำเนินเป้าหมายต่อได้แม้ผู้เล่นไม่สนใจ และความสัมพันธ์เปลี่ยนจากการกระทำจริง

# 5. ความสัมพันธ์ ครอบครัว และความภักดี

\[ฐานเดิม\] มีคู่สมรสหลายคน ศิษย์ อาจารย์ พี่น้องร่วมสาบาน ค่าความสนิท และผลข้ามรุ่น

\[ข้อเสนอใหม่\] อย่าใช้ค่าความสนิทค่าเดียวแทนทุกอย่าง ให้แยกความรัก ความเชื่อใจ
ความเคารพ ความกลัว หนี้บุญคุณ ความอิจฉา ความแค้น ความภักดี และความเห็นต่าง
แสดงเฉพาะค่าที่ช่วยตัดสินใจ ไม่จำเป็นต้องเปิดเผยทั้งหมด

คนหนึ่งอาจรักผู้เล่นแต่ไม่เชื่อใจ หรือกลัวแต่ยังภักดีเพราะคำสัตย์
การให้ของขวัญแพงไม่ควรลบความแค้นจากการทรยศร้ายแรงได้ง่าย ๆ

กิจกรรมความสัมพันธ์ควรมีการสนทนา ให้ของขวัญตามรสนิยม ช่วยเหลือ ฝึกวิชาร่วม รักษาคำสัญญา
ขอโทษ/ชดใช้ เปิดเผยความลับ ขอความช่วยเหลือ และยุติความสัมพันธ์อย่างมีผลตามมา

## 5.1 ครอบครัวและทายาท

ลูกแต่ละคนมีบุคลิก ความถนัด สุขภาพ ความสัมพันธ์กับพ่อแม่และพี่น้อง
การศึกษาเปลี่ยนความสามารถ/บุคลิก ทายาทที่เก่งที่สุดอาจไม่ใช่ผู้นำที่เหมาะสม
ลูกอาจปฏิเสธตำแหน่งหรือออกจากตระกูล การลำเอียงสร้างความขัดแย้ง
และการแต่งงานเป็นพันธมิตรทางการเมืองได้โดยคู่สมรสยังมีเป้าหมายของตัวเอง

## 5.2 ครัวเรือนหลายคู่สมรส

\[ฐานเดิม\] รองรับภรรยาหลัก ภรรยารอง ความหึงหวง การลำเอียงและการแย่งมรดก

ขยายด้วยเป้าหมายและความยินยอมของคู่สมรส ความสัมพันธ์ระหว่างคู่สมรส
ความมั่นคงทางการเงิน ความคาดหวังจากครอบครัวฝ่ายคู่สมรส การดูแลลูก
และผลจากชื่อเสียง/กฎหมายในยุคและภูมิภาค อย่าทำให้เป็นระบบสะสมคู่สมรสเพื่อโบนัสเท่านั้น

## 5.3 อาจารย์และศิษย์

มีการคัดเลือกศิษย์ การถ่ายทอดวิชา คำสอนที่ศิษย์อาจเชื่อฟังหรือปฏิเสธ ความริษยาระหว่างศิษย์
ความผิดพลาดของอาจารย์ การทรยศ/คืนดี และการเลือกผู้สืบทอดที่ทำให้เกิดความขัดแย้ง
ศิษย์ต้องเติบโตเป็นคนที่มีเป้าหมายของตัวเอง ไม่ใช่เครื่องมือของผู้เล่น

# 6. วิชาและการเติบโตด้านยุทธ์

\[ฐานเดิม\] มีวิชาหลายประเภท ระดับตำรา ระดับความชำนาญ การสร้างวิชาเอง
ความเข้ากันได้ และความเสี่ยงลมปราณแปรปรวน

\[ข้อเสนอใหม่\] วิชาต้องให้เอกลักษณ์ในการเล่น ไม่ใช่โบนัสตัวเลขอย่างเดียว

แต่ละวิชาควรมีประเภท ระยะโจมตี รูปแบบการใช้ ความต้องการร่างกาย/ลมปราณ ความชำนาญ
จุดแข็ง/จุดอ่อน ความเข้ากันได้ ต้นทุนฝึก ความเสี่ยงเมื่อใช้ผิด เจ้าของตำรา
และเงื่อนไขเรียนรู้/ถ่ายทอด

ระดับความชำนาญควรปลดล็อกทางเลือก: เริ่มเรียนใช้ท่าพื้นฐาน
ชำนาญน้อยลดต้นทุน/ความผิดพลาด ชำนาญใหญ่ปลดล็อกการประยุกต์ สมบูรณ์เพิ่มกลยุทธ์
และเหนือรูปแบบเป็นความสำเร็จหายาก ไม่ใช่เพิ่มพลังอย่างเดียว

การสร้างวิชาใหม่ต้องใช้ความเข้าใจ ประสบการณ์ วิชาต้นแบบ เวลา ทรัพยากร และความเสี่ยง
วิชาอาจไม่เสถียรในช่วงแรกและค่อยปรับปรุงจากการใช้จริง

รูปแบบฝึกต้องต่างกัน: ฝึกปลอดภัยโตช้า ฝึกหนักโตเร็วแต่เสี่ยง ฝึกกับอาจารย์มีค่าใช้จ่ายแต่ตรงจุด
ฝึกจากตำราตีความผิดได้ ฝึกจริงได้ประสบการณ์แต่เสี่ยง และปิดด่านฝึกได้ผลมากแต่โลกดำเนินต่อ

\[ฐานเดิม\] คนส่วนใหญ่ควรอยู่ระดับต่ำและยอดฝีมือระดับสูงหายาก
ใช้การจำลองประชากรตรวจการกระจายระดับพลัง จำกัดการเติบโตจากการฝึกซ้ำวิธีเดียว
และให้การชนะขึ้นกับพลัง ความชำนาญ กลยุทธ์ อาวุธ สุขภาพและข้อมูล ไม่ใช่สุ่มล้วน

# 7. การต่อสู้ บาดแผลถาวร และเส้นทางหลังความพ่ายแพ้

\[ฐานเดิม\] ต่อสู้สั้น 1--3 รอบ มีโจมตี ตั้งรับ ท่าไม้ตาย อาวุธลับ หลบหนีและยอมแพ้
บาดแผลอาจถาวร

\[ข้อเสนอใหม่\] ความเสี่ยงต้องชัด แต่ไม่ลงโทษอย่างไร้เหตุผล

## 7.1 การประเมินความเสี่ยง

แสดงโอกาสสำเร็จที่มาจากสูตรจริง ความเสี่ยงบาดเจ็บ/เสียอวัยวะ/เสียชีวิต ต้นทุนพลังงาน
ผลต่อชื่อเสียงและภารกิจ และสิ่งที่ยังไม่รู้ หากข้อมูลไม่พอ ห้ามแสดงเปอร์เซ็นต์ที่แม่นยำเกินจริง
ให้ใช้ระดับต่ำ/กลาง/สูงหรือช่วงที่อธิบายได้

โอกาส 90% ยังล้มเหลวได้ แต่ผลระยะยาวต้องใกล้เคียงความน่าจะเป็นที่แสดง
ห้ามเปลี่ยนโอกาสลับหลังผู้เล่นเลือกโดยไม่มีระบบรองรับ
การเสี่ยงถึงตายต้องเตือนตามข้อมูลที่ตัวละครรู้ได้

## 7.2 บาดแผลเปลี่ยนวิธีเล่น

แขนขาดอาจฝึกอีกมือหรือเป็นครู ลมปราณเสียหายอาจหันไปใช้วิชาภายนอก การแพทย์ การค้า
หรือสืบสวน ตาบอดอาจฝึกฟังเสียง ขาพิการใช้เครื่องช่วยหรือเปลี่ยนบทบาท
พิษเรื้อรังต้องบริหารเงินและยา ไม่รับประกันว่าทุกบาดแผลรักษาได้
แต่ต้องมีทางเล่นต่อที่มีความหมาย

## 7.3 ผลสะท้อนจากความรุนแรง

การทรมาน ประหาร สังหารหมู่และทำลายสำนักส่งผลต่อชื่อเสียงเฉพาะกลุ่ม ความกลัว การต่อต้าน
ความทรงจำผู้รอดชีวิต กฎหมาย ความสัมพันธ์ และผลข้ามรุ่น ความรุนแรงไม่ควรคุ้มค่าที่สุดเสมอ
และไม่ควรถูกลงโทษเท่ากันทุกบริบท

## 7.4 คู่ต่อสู้ปรับตัว

ผู้รอดชีวิตอาจเรียนรู้รูปแบบวิชา เตรียมยา/อาวุธ/พรรคพวก เปลี่ยนแผน หนี ยอมแพ้
หรือคืนดีตามบุคลิกและเป้าหมาย การปรับตัวต้องมีเหตุผลและข้อมูล
ไม่ใช่เพิ่มค่าสถานะลับเพื่อเอาชนะผู้เล่น

# 8. สำนัก การเมือง และอำนาจ

\[ฐานเดิม\] มีฝ่ายธรรมะ ฝ่ายอธรรม พรรคมาร สำนัก/ตระกูลของผู้เล่น อันดับ ฉายา ฮ่องเต้
มารสวรรค์ จอมมารและเทพเซียน

\[ข้อเสนอใหม่\] การเมืองควรเป็นระบบผลประโยชน์ ไม่ใช่เพียงแถบความสัมพันธ์

## 8.1 โปรไฟล์สำนัก

มีผู้นำและผู้สืบทอด เป้าหมาย คำสอน ทรัพยากร เงิน กำลังคน อาณาเขต วิชาเฉพาะ จุดอ่อน
ปัญหาภายใน พันธมิตร ศัตรู ความชอบธรรม และความมั่นคงในการสืบทอด

## 8.2 ความสัมพันธ์ระหว่างฝ่าย

ใช้ความไว้วางใจ ผลประโยชน์ ดินแดน หนี้บุญคุณ อุดมการณ์ ความกลัว ประวัติทรยศ
และความจำเป็นร่วมมือ ฝ่ายธรรมะไม่จำเป็นต้องดีทั้งหมด ฝ่ายอธรรมไม่จำเป็นต้องเลวทั้งหมด
และพรรคมารควรมีอุดมการณ์/ความขัดแย้งภายใน

## 8.3 การบริหารสำนัก

มีงบประมาณ รายรับรายจ่าย การรับศิษย์ ความภักดี ขวัญกำลังใจ ความขัดแย้ง อาคารที่มีผลจริง
ธุรกิจเสริม การป้องกันอาณาเขต การพัฒนาวิชา การเจรจาพันธมิตร การเลือกผู้สืบทอด
และความเสี่ยงแทรกซึม สำนักใหญ่มีรายได้มากแต่ต้นทุนสูงและเป็นเป้าหมายมากขึ้น

## 8.4 ราชสำนัก

เพิ่มอิทธิพลระหว่างขุนนาง ทหารและฝ่ายใน ความชอบธรรมราชวงศ์ ภาษี เสบียง ความสงบ
การสนับสนุนประชาชน การสืบทอดบัลลังก์ ข่าวกรอง และการโฆษณาชวนเชื่อ
การกบฏควรมีสาเหตุจากแรงกดดันสะสม ไม่ใช่สุ่มโดยไร้เหตุผล

## 8.5 ระบบราชสำนักและวังหลัง (Imperial Court & Inner Palace)

**สถานะ: ข้อเสนอใหม่ที่ต้องผสานกับระบบราชสำนัก ความสัมพันธ์ ครอบครัว ข่าวลือ NPC และ Chronicle**

ระบบนี้มีไว้เพิ่มมิติทางการเมืองและชีวิต ไม่ใช่สร้างฉากดราม่าในวังอย่างโดดเดี่ยว ทุกตัวละครในราชสำนักต้องมีแรงจูงใจ ทรัพยากร ข้อมูลที่ตนรู้ ความสัมพันธ์ ความเสี่ยง และผลจากการตัดสินใจ เช่นเดียวกับ NPC คนอื่นในโลก

### 8.5.1 โครงสร้างอำนาจ

จำลองตำแหน่งหลักตามความเหมาะสมของยุคและขนาดเกม:

- **ฮ่องเต้:** ผู้มีอำนาจสูงสุดอย่างเป็นทางการ แต่ถูกจำกัดด้วยความชอบธรรม สุขภาพ กองทัพ ขุนนาง เสบียง เงินในท้องพระคลัง ความนิยม และความสามารถในการควบคุมข้อมูล
- **ฮองเฮา:** ประมุขฝ่ายใน มีอิทธิพลจากฐานะตามกฎหมาย เครือญาติ ตระกูลเดิม ความไว้วางใจของฮ่องเต้ ความสัมพันธ์กับพระโอรส/พระธิดา และความสามารถในการจัดการความขัดแย้งในวัง
- **สนมและฝ่ายใน:** แต่ละคนมีภูมิหลัง เป้าหมาย ความภักดี เครือข่ายผู้สนับสนุน ความสัมพันธ์กับฮองเฮาและทายาท รวมถึงต้นทุนของการแย่งชิงอำนาจ ไม่ใช่ทุกคนต้องเป็นศัตรูกัน
- **ขันที:** เป็นกลุ่มบุคลากรในวังที่อาจดูแลประตู เอกสาร การเข้าเฝ้า ทรัพย์สิน ข่าวสาร และงานส่วนพระองค์ อำนาจเกิดจากการเข้าถึงข้อมูลและผู้มีอำนาจ ไม่ใช่ค่าสถานะลึกลับที่ทำให้ควบคุมทุกอย่างได้
- **องค์รัชทายาทและเชื้อพระวงศ์:** มีความสามารถ ผู้สนับสนุน คู่แข่ง ความชอบธรรม สุขภาพ บุคลิก และมุมมองต่อการปกครองต่างกัน
- **ขุนนาง แม่ทัพ และตระกูลใหญ่:** สนับสนุนราชวงศ์ตามผลประโยชน์ ความเชื่อ ความสัมพันธ์ หนี้บุญคุณ หรือความกลัว และอาจเปลี่ยนฝ่ายเมื่อเงื่อนไขเปลี่ยน

ตำแหน่งเหล่านี้ควรปรับตาม setting ที่มีอยู่ ไม่จำเป็นต้องสร้างตำแหน่งทุกชนิดหากไม่มีบทบาทในการเล่นจริง

### 8.5.2 ฮองเฮา ตระกูล และการเมืองฝ่ายใน

ฮองเฮาไม่ควรเป็นเพียงตัวละครที่มีค่าความสัมพันธ์กับฮ่องเต้ แต่ควรมีระบบย่อยที่เชื่อมต่อกับการเมืองส่วนกลาง:

- มีเป้าหมายระยะสั้นและระยะยาว เช่น รักษาเสถียรภาพในวัง ปกป้องบุตร สร้างความชอบธรรมให้รัชทายาท ลดอิทธิพลของฝ่ายคู่แข่ง หรือยุติความขัดแย้ง
- ตระกูลเดิมอาจให้กำลังคน เงิน ข่าวสาร หรือแรงสนับสนุน แต่การพึ่งตระกูลมากเกินไปอาจทำให้ขุนนางและประชาชนหวาดระแวง
- ความสัมพันธ์กับฮ่องเต้ สนม รัชทายาท ขันที และขุนนางต้องเป็นคนละแกน ไม่รวมทุกอย่างเป็นคะแนนเดียว
- การตัดสินใจอาจสร้างผลทั้งดีและเสีย เช่น การแต่งตั้งญาติช่วยให้บริหารได้เร็วขึ้นแต่เพิ่มข้อครหาเรื่องพวกพ้อง
- ฮองเฮาอาจเป็นผู้ประสานฝ่ายที่ขัดแย้ง ผู้ปกป้องผู้เล่น หรือคู่แข่งทางการเมืองได้ ขึ้นกับประวัติและเหตุการณ์ ไม่ใช่บทบาทตายตัว

### 8.5.3 ระบบขันทีและเครือข่ายข่าวสาร

ขันทีแต่ละคนควรมีระดับตำแหน่ง หน้าที่ ความภักดี ความทะเยอทะยาน ความกลัว หนี้บุญคุณ และผู้ที่ตนพึ่งพาได้ อำนาจของขันทีมาจากหน้าที่และเครือข่าย เช่น:

- **การเข้าถึง:** ใครสามารถเข้าเฝ้า ส่งสาร เปิดประตู หรือจัดคิวพบผู้มีอำนาจ
- **เอกสารและคำสั่ง:** ใครรับ ส่ง คัดกรอง หรือเก็บรักษาสารและเอกสาร โดยต้องมีโอกาสเกิดความผิดพลาดหรือการตรวจสอบ ไม่ใช่แก้คำสั่งได้โดยไร้ร่องรอย
- **ข่าวสาร:** ใครได้ยินอะไร จากใคร เมื่อใด และข่าวนั้นเชื่อถือได้เพียงใด
- **เครือข่ายอุปถัมภ์:** ความสัมพันธ์กับฮ่องเต้ ฮองเฮา สนม รัชทายาท ขุนนาง ทหาร พ่อค้า หรือสำนักยุทธ์
- **ความเสี่ยง:** ถูกใส่ร้าย ถูกตรวจสอบ ถูกโยกย้าย ถูกหักหลัง หรือสูญเสียอำนาจเมื่อผู้สนับสนุนตาย/พ้นตำแหน่ง

อย่าทำให้ขันทีทุกคนเป็นตัวร้ายหรือผู้บงการ บางคนซื่อสัตย์ ทำงานเพื่อความอยู่รอด บางคนเห็นแก่ประโยชน์ส่วนตน และบางคนเปลี่ยนใจเมื่อเงื่อนไขเปลี่ยน ความภักดีเป็นความน่าจะเป็นจากประวัติและแรงจูงใจ ไม่ใช่ป้ายถาวร

### 8.5.4 การสืบทอดบัลลังก์และวิกฤตผู้สืบทอด

การสืบทอดต้องพิจารณามากกว่าลำดับอายุ โดยอาจมีปัจจัยเหล่านี้:

- สถานะทางกฎหมายและการรับรองเป็นรัชทายาท
- ความสามารถ สุขภาพ บุคลิก และประสบการณ์ของผู้สืบทอด
- การสนับสนุนจากฮ่องเต้ ฮองเฮา สนม ตระกูล ขุนนาง กองทัพ และประชาชน
- ความชอบธรรมจากธรรมเนียม กฎหมาย ผลงาน และข่าวลือ
- หนี้สิน ความลับ ความผิดในอดีต และคำมั่นสัญญาที่แต่ละฝ่ายต้องรักษา
- ความเสี่ยงจากการสิ้นพระชนม์ก่อนเวลา การสละสิทธิ์ การถูกปลด การแต่งตั้งผู้สำเร็จราชการ หรือการแย่งชิงอำนาจ

หากไม่มีทายาทที่เหมาะสม โลกต้องมีทางออกหลายแบบ เช่น แต่งตั้งเชื้อพระวงศ์สายอื่น สภาขุนนาง/ผู้สำเร็จราชการ การประนีประนอม การแบ่งขั้ว หรือสงครามสืบราชสมบัติ ผลลัพธ์ต้องเกิดจากสถานะและแรงกดดันสะสม ไม่ใช่สุ่มเพื่อบังคับให้เกิดดราม่า

### 8.5.5 ข่าวลือ การสืบสวน และความจริงหลายระดับ

เหตุการณ์ในวังต้องใช้ระบบข่าวสารเดียวกับบทที่ 10:

1. **ข้อเท็จจริง:** สิ่งที่เกิดขึ้นจริงใน world state
2. **พยาน/หลักฐาน:** สิ่งที่ตัวละครแต่ละคนเห็น ได้ยิน หรือเก็บไว้
3. **ข่าวลือ:** ข้อมูลที่อาจผิด บิดเบือน หรือมีผู้จงใจปล่อย
4. **ความเชื่อของตัวละคร:** การตีความตามอคติ ความสัมพันธ์ และความรู้ที่มี
5. **สิ่งที่ผู้เล่นรู้:** ต้องไม่เปิดเผยความจริงทั้งหมด หากตัวละครยังไม่มีเหตุผลจะรู้

การใส่ร้ายหรือปลอมเอกสารควรทิ้งร่องรอยและมีโอกาสถูกตรวจพบ การสืบสวนอาจใช้พยานหลายคน บันทึกเข้าออก เส้นทางเงิน การเปลี่ยนเวร หรือความขัดแย้งในคำให้การ แต่ไม่ควรรับประกันว่าทุกคดีมีคำตอบครบถ้วน

### 8.5.6 ภารกิจและสายเหตุการณ์ตัวอย่าง

ใช้เป็นแม่แบบสำหรับ event chain ไม่ใช่เหตุการณ์บังคับที่ต้องเกิดทุกเซฟ:

- **สารที่หายไป:** คำสั่งสำคัญหายระหว่างส่ง ผู้เล่นเลือกค้นหา เจรจา เปิดโปง หรือปิดเรื่องเพื่อป้องกันวิกฤต ผลลัพธ์เปลี่ยนตามหลักฐานและผู้ที่ได้รับประโยชน์
- **รัชทายาทที่ถูกตั้งข้อสงสัย:** มีข่าวลือเรื่องการทรยศ ผู้เล่นอาจตรวจสอบหลักฐาน ปกป้องผู้ถูกกล่าวหา หรือใช้สถานการณ์ต่อรอง แต่การเลือกโดยไม่มีหลักฐานอาจทำลายความไว้วางใจ
- **การแต่งตั้งที่ขัดแย้ง:** ฮองเฮาหรือขุนนางเสนอคนของตนให้ตำแหน่ง การยอมรับอาจเพิ่มประสิทธิภาพและหนี้บุญคุณ แต่เพิ่มความเสี่ยงเรื่องพวกพ้อง
- **ขันทีผู้รู้ความลับ:** ขันทีเสนอข้อมูลแลกกับความคุ้มครอง เงิน หรือการช่วยเหลือ ต้องประเมินความน่าเชื่อถือและผลประโยชน์ที่ซ่อนอยู่
- **วิกฤตเสบียงในวัง:** ปัญหาอาจมาจากการทุจริต ภัยพิบัติ การขนส่ง หรือการกล่าวหาเท็จ แก้ผิดจุดจะทำให้ความนิยมและความชอบธรรมลดลง
- **ผู้สำเร็จราชการ:** เมื่อฮ่องเต้ประชวรหรือรัชทายาทยังเยาว์ ฝ่ายต่าง ๆ แข่งขันเพื่อดูแลราชการ โดยมีผลต่อภาษี กองทัพ และสำนักยุทธ์
- **การล้างมลทินข้ามรุ่น:** ตัวละครรุ่นหลังค้นพบหลักฐานที่เปลี่ยนความเข้าใจต่อบรรพบุรุษ อาจฟื้นชื่อเสียงหรือเปิดบาดแผลเก่าของตระกูล

ทุก event ต้องระบุเงื่อนไขเริ่มต้น ผู้เกี่ยวข้อง หลักฐานที่มี ตัวเลือก ผลทันที ผลล่าช้า flags/callbacks และวิธีป้องกันการเกิดซ้ำอย่างไม่เหมาะสม

### 8.5.7 เส้นทางผู้เล่น

ผู้เล่นไม่จำเป็นต้องเป็นเชื้อพระวงศ์จึงมีส่วนร่วมได้ เส้นทางที่เป็นไปได้ตามระบบอาชีพและการเมืองเดิม ได้แก่:

- จอมยุทธ์หรือศิษย์สำนักที่ถูกเรียกเข้าวังเพื่อคุ้มกัน/สืบสวน
- หมอหรือแพทย์หลวงที่ต้องตัดสินใจเรื่องความลับทางการแพทย์และความปลอดภัย
- พ่อค้า ผู้จัดส่งเสบียง หรือผู้ให้กู้ที่เกี่ยวข้องกับเงินและเครือข่ายอุปถัมภ์
- ขุนนาง เจ้าหน้าที่ หรือผู้ช่วยราชการที่เติบโตผ่านผลงานและพันธมิตร
- ผู้ส่งสาร นักสืบ หรือผู้รวบรวมข่าวที่ต้องแยกข้อเท็จจริงออกจากข่าวลือ
- ผู้สืบทอดจากตระกูลที่เคยพัวพันกับการเปลี่ยนราชวงศ์และต้องรับผลจากชื่อเสียงเดิม

สิทธิ์เข้าถึงตำแหน่งและสถานที่ต้องมาจากภูมิหลัง สถานะ ความสัมพันธ์ ภารกิจ หรือใบอนุญาตที่สมเหตุผล ไม่ใช่เปิดทุกพื้นที่ให้ผู้เล่นตั้งแต่ต้น

### 8.5.8 ผลระยะยาวและการเชื่อมระบบ

การตัดสินใจในราชสำนักควรส่งผลต่อ:

- **NPC/ความทรงจำ:** ผู้เกี่ยวข้องจดจำว่าใครช่วย ใครทรยศ ใครเปิดโปงความลับ และใครได้ประโยชน์
- **ครอบครัว/สายสืบทอด:** การแต่งงาน การรับรองบุตร มรดก ชื่อเสียงตระกูล และสิทธิ์ในตำแหน่ง
- **สำนัก/ฝ่ายยุทธ์:** การแต่งตั้งแม่ทัพ การสนับสนุนสำนัก การกวาดล้าง หรือการให้สิทธิ์เข้าถึงทรัพยากร
- **เศรษฐกิจ:** ภาษี การทุจริต ราคาสินค้า เสบียง การค้า และหนี้ของตระกูล
- **ข่าวลือ/ความชอบธรรม:** เรื่องเล่าที่แพร่กระจายและความแตกต่างระหว่างความจริงกับสิ่งที่ประชาชนเชื่อ
- **โลกและยุค:** การเปลี่ยนราชวงศ์ สงครามกลางเมือง การปฏิรูป หรือช่วงฟื้นฟูหลังวิกฤต
- **Chronicle:** บันทึกว่าใครได้บัลลังก์ เหตุใดฝ่ายหนึ่งจึงชนะ ใครถูกกล่าวหา และหลักฐานที่คนรุ่นหลังอาจค้นพบ

ห้ามใช้คะแนนความสัมพันธ์ตัวเดียวตัดสินการเมืองทั้งหมด ให้คำนวณผลจากอำนาจ ทรัพยากร ความชอบธรรม ข้อมูล ความเสี่ยง ความสัมพันธ์ และเวลาที่เหลือก่อนวิกฤต

### 8.5.9 กติกาสำคัญเพื่อความสมจริงและเล่นซ้ำได้

- ไม่ใช่ทุกเซฟต้องเกิดการแย่งบัลลังก์ การลอบสังหาร หรือการกวาดล้าง
- ไม่ใช่ทุกขันที สนม ฮองเฮา หรือขุนนางต้องมีแผนร้าย
- ตัวละครอาจเข้าใจผิด ตัดสินใจพลาด เปลี่ยนใจ หรือเลือกความสงบแทนผลประโยชน์
- การกระทำสำคัญต้องมีต้นทุน ความเสี่ยง และหลักฐานให้ผู้เล่นสืบค้นตามสมควร
- ผู้เล่นต้องมีทางเลือกไม่ยุ่งการเมือง หรือถอนตัวเมื่อเป็นไปได้ แต่โลกยังดำเนินต่อและผลกระทบอาจมาถึงภายหลัง
- ใช้จำนวน NPC ที่มีบทบาทจริงก่อนขยายตัวละครฝ่ายในจำนวนมาก หลีกเลี่ยงการจำลองตัวละครทุกคนด้วยความละเอียดเท่ากัน
- แยกกฎเกมออกจากธรรมเนียมเชิงเรื่องเล่า และหลีกเลี่ยงการใช้ความรุนแรงต่อผู้หญิง/ขันทีเป็นเพียงเครื่องมือสร้างความตื่นเต้น

## 8.6 ตัวตนระดับตำนาน

รักษาความแตกต่างเดิม: มารสวรรค์คือผู้นำพรรคมาร จอมมารคือภัยพิบัติระดับโลกที่พบไม่บ่อย
เทพเซียนอยู่เหนือยุทธภพและมีบทบาทจำกัด
อย่าให้ตัวละครระดับตำนานปรากฏบ่อยจนหมดความน่าเกรงขาม
และอธิบายว่าทำไมพวกเขาไม่แก้ทุกปัญหาเอง

# 9. เศรษฐกิจและทรัพยากร

\[ฐานเดิม\] ใช้เงินอีแปะ/เหวิน ตำลึงเงิน ตำลึงทอง ราคาสินค้าเปลี่ยนตามยุคและภัยพิบัติ

\[ข้อเสนอใหม่\] ให้เศรษฐกิจส่งผลต่อชีวิต แต่ไม่จำลองตลาดทุกชิ้นทุกเมืองอย่างหนักเกินไป

ปัจจัยได้แก่ฤดูกาล ผลผลิต ภัยแล้ง น้ำท่วม โรคระบาด สงคราม เส้นทางการค้า โจร ภาษี
ความมั่นคง ความต้องการยา/อาวุธ/เสบียง และแรงงาน ผลต่อผู้เล่นคือค่าครองชีพ ค่ารักษา
เงินเดือน ราคาวัตถุดิบ หนี้ ความเสี่ยงงานคุ้มภัย และความสามารถเลี้ยงครอบครัว/สำนัก

ป้องกันเศรษฐกิจพังด้วยการกำหนดแหล่งเงินเข้าออก ตรวจการทำซ้ำกิจกรรมเพื่อสร้างเงินไม่จำกัด
จำกัดเงินเฟ้อ มีแหล่งรายได้หลายแบบแต่มีข้อแลกเปลี่ยน และทดสอบทั้งผู้เล่นร่ำรวยกับผู้เล่นยากจน

อาชีพต้องมีตัวตน: ช่างตีอาวุธสร้างอาวุธมีชื่อ แพทย์สร้างสูตรยา พ่อค้าสร้างเครือข่าย
นักเล่าเรื่องเผยแพร่ตำนาน มือปราบต้องเลือกระหว่างกฎหมายกับคำสั่ง
เสนาธิการจัดเสบียง/ข่าวกรอง และเจ้าสำนักบริหารคนกับความชอบธรรม

# 10. ข่าวลือ การสืบสวน และข้อมูลไม่สมบูรณ์

ข่าวลือจากโรงน้ำชาไม่ควรเป็นแค่ปุ่มสุ่มภารกิจ แหล่งข่าวได้แก่พ่อค้า นักเล่าเรื่อง ศิษย์สำนัก
มือปราบ สายข่าว เอกสารเก่า ผู้รอดชีวิต และข่าวที่คู่แข่งจงใจปล่อย

ข่าวแต่ละเรื่องควรมีแหล่ง เวลา ความน่าเชื่อถือ ผลประโยชน์ของผู้ปล่อย วิธีตรวจสอบ
และความเสี่ยงเป็นกับดัก ผู้เล่นรวบรวมเบาะแส เปรียบเทียบคำให้การ ใช้ความรู้เฉพาะด้าน
และเลือกกล่าวหาแม้หลักฐานไม่ครบได้
บางเรื่องอาจไม่มีหลักฐานพอหรือความจริงไม่ตรงกับข่าวแรก

# 11. โลกเปลี่ยนตามยุคและวิกฤต

\[ฐานเดิม\] มีวัฏจักรสงบ คอร์รัปชัน/อดอยาก โกลาหล/ขุนศึก การรวมแผ่นดิน
และสงครามระหว่างธรรมะกับพรรคมาร

\[ข้อเสนอใหม่\] ให้ยุคเปลี่ยนผ่านจากแรงกดดันสะสม เช่น ความชอบธรรมราชวงศ์
ความมั่นคงอาหาร ความไม่พอใจประชาชน อำนาจขุนศึก ความขัดแย้งสำนัก
โรคระบาดและเส้นทางการค้า ไม่ใช่เปลี่ยนเพราะตัวนับเวลาถึงเลขที่กำหนดเท่านั้น

วิกฤตมีห้าระยะ: สัญญาณเตือน → การเตรียมตัว/เจรจา → วิกฤต → ผลลัพธ์ → ผลระยะยาว เช่น
ผู้ลี้ภัย หนี้สงคราม การล้างแค้นและการฟื้นฟู

ภูมิภาคต่างกันด้านภูมิประเทศ เศรษฐกิจ วิชา สำนัก กฎหมาย ภัยธรรมชาติ เทศกาลและอาชีพ
การเดินทางมีต้นทุนแต่ไม่ควรยืดเยื้อโดยไม่มีการตัดสินใจ

# 12. การเล่นข้ามรุ่นและ Chronicle

\[ฐานเดิม\] เมื่อตัวละครตาย เล่นต่อเป็นลูก ศิษย์ หรือคนใหม่ในโลกเดิม โลกเก็บประวัติ
ตำนาน สำนัก สุสาน ตำราและความแค้น

\[ข้อเสนอใหม่\] แยกสิ่งที่สืบทอดได้และสิ่งที่ต้องพิสูจน์ใหม่

สิ่งที่อาจส่งต่อ: เงิน/ทรัพย์สินบางส่วน อาวุธประจำตระกูล บ้าน ธุรกิจ สำนัก ตำรา
วิชาที่ถ่ายทอด ชื่อเสียง หนี้ พันธะ พันธมิตร ศัตรู ข่าวลือ ความลับและเป้าหมายที่ยังไม่สำเร็จ

สิ่งที่ไม่ควรถ่ายโอนอัตโนมัติ: ความชำนาญทั้งหมด ความสัมพันธ์ส่วนตัวทุกอย่าง ความภักดีของศิษย์
ตำแหน่งที่ต้องได้รับการยอมรับ ความจริงที่รุ่นใหม่ไม่มีทางรู้ และอำนาจที่ต้องใช้ทรัพยากรรักษาไว้

สำนักอาจเติบโต เสื่อม แตกฝ่าย ถูกแทรกซึม เปลี่ยนแนวทาง สูญเสียวิชา
หรือกลายเป็นตำนานที่คนเข้าใจผิด Chronicle จัดหมวดชีวิตแต่ละรุ่น เหตุการณ์โลก ประวัติสำนัก
คนสำคัญ หนี้/แค้น ตำราหายสาบสูญ สุสาน ข่าวลือ และสายตระกูล
ทุกบันทึกควรมีแหล่งที่มาและเวลา

ก่อนเปลี่ยนรุ่นให้สรุปความสำเร็จ ความล้มเหลว คนที่ได้รับผล คำสัญญาค้าง
ทรัพย์สิน/วิชาที่ส่งต่อได้ และสภาพครอบครัว/สำนัก จากนั้นเลือกเล่นต่อเป็นลูก ศิษย์ หรือคนใหม่

# 13. การเล่นซ้ำและเส้นทางชีวิต

ผู้เล่นควรเริ่มใหม่เพราะอยากทดลองชีวิตต่างกัน ไม่ใช่ถูกบังคับให้เริ่มใหม่
ความแตกต่างมาจากภูมิหลัง ครอบครัว ภูมิภาค ความถนัด บุคลิก เป้าหมาย ความสัมพันธ์
สำนักในยุคนั้น วิกฤต ข่าวลือ การเลือกของ NPC และการตัดสินใจผู้เล่น
สุ่มเฉพาะส่วนที่สร้างความหลากหลาย ห้ามสุ่มจนโลกไร้เหตุผล

เส้นทางที่ควรเล่นได้จริง: จอมยุทธ์พเนจร ผู้ก่อตั้งสำนัก แพทย์/ผู้เชี่ยวชาญพิษ
พ่อค้า/หัวหน้ากองคาราวาน มือปราบ/ขุนนาง เสนาธิการ/แม่ทัพ นักฆ่า นักวิชาการ/นักเล่าเรื่อง
ผู้นำพรรคมาร ผู้บริหารที่เน้นการเมือง ผู้พิการที่เปลี่ยนสาย ผู้ดูแลครอบครัว และผู้แสวงหาเซียน
ทุกเส้นทางต้องมีระบบและเหตุการณ์เฉพาะ ไม่ใช่เปลี่ยนชื่ออาชีพเท่านั้น

ความสำเร็จหลายรูปแบบ: ครอบครัวปลอดภัย สำนักอยู่รอดหลายรุ่น สร้างตำรา ยุติสงคราม
เปิดโปงทุจริต รักษาคนจำนวนมาก สร้างตำนานการค้า ตั้งราชวงศ์
หรือให้อภัยและหลุดพ้นจากวงจรความแค้น
การบรรลุเซียนไม่ควรเป็นเป้าหมายที่ดีที่สุดเพียงอย่างเดียว

# 14. มาตรฐานเหตุการณ์ 600+

\[ฐานเดิม\] เป้าหมายคือ 600+ เหตุการณ์ แบ่งตามช่วงชีวิตและเหตุการณ์โลก

\[ข้อเสนอใหม่\] จำนวน 600 เป็นเป้าหมายเนื้อหา ไม่ใช่ตัวชี้วัดคุณภาพ ทุกเหตุการณ์ควรมี ID
ไม่ซ้ำ ชื่อ ช่วงอายุ/เวลา ภูมิภาค/ยุค เงื่อนไขเกิด/ห้ามเกิด ตัวละครและสำนัก บริบท ตัวเลือก
2--4 แบบ ข้อดีข้อเสีย ความเสี่ยงและโอกาสจริง ผลทันที ผลระยะยาว flags ความทรงจำ
ข่าวที่แพร่ ผลต่อความสัมพันธ์/เงิน/บาดแผล ผลข้ามรุ่น เหตุการณ์ถัดไป
และเงื่อนไขป้องกันการเกิดซ้ำ

สัดส่วนเริ่มต้นที่เสนอ: 35% เหตุการณ์สั้นชีวิตประจำวัน 35% เชื่อมระบบ/ความสัมพันธ์ 20%
สายเรื่อง 2--6 ตอน 10% เหตุการณ์หายาก/ระดับโลก ปรับจาก playtest ได้ ไม่ใช่กฎตายตัว

ป้องกันเหตุการณ์ซ้ำด้วย cooldown ประวัติการพบ เงื่อนไขบริบทจริง
และเงื่อนไขต่อเนื่องที่ตรวจสถานะตัวละคร หลีกเลี่ยง variation ที่เปลี่ยนเพียงชื่อ

เนื้อหาต้องมีหลายอารมณ์: ครอบครัว มิตรภาพ อารมณ์ขัน การเรียนรู้ การสูญเสีย การยอมรับ
ความสงบหลังสงคราม การกลับมาพบกัน ความเข้าใจผิดที่คลี่คลาย และความสำเร็จที่ต้องแลก
ความสงบทำให้เหตุการณ์ใหญ่มีน้ำหนักขึ้น

# 15. UI/UX

\[ฐานเดิม\] มีแท็บชีวิต ฝึกฝน ยุทธภพ คน กิจกรรม และบันทึกยุทธภพ
รวมถึงหน้าสรุปหลังความตาย

\[ข้อเสนอใหม่\] หน้าแรกควรเห็นชื่อ อายุ เพศ ฉายา ขั้นพลัง กำลังภายใน
สุขภาพ/บาดแผลสำคัญ เป้าหมายชีวิต เงิน/หนี้ เหตุการณ์เร่งด่วน และปุ่มดำเนินปี
รายละเอียดอื่นเปิดดูได้ ไม่ต้องแสดงทุกค่าในหน้าเดียว

ตัวเลือกแสดงผลที่คาด ความเสี่ยงที่รู้ได้ ค่าใช้จ่าย เงื่อนไข ผลต่อคนอื่น และความไม่แน่นอน
หากเลือกไม่ได้ให้บอกเหตุผล เช่น ไม่มีวิชา เงิน ความสัมพันธ์ หรือมีบาดแผล

บันทึกเหตุการณ์เรียงตามเวลา กรองตามบุคคล สำนัก ภูมิภาคและประเภท
คลิกชื่อเพื่อดูรายละเอียด แยกข้อเท็จจริงจากข่าวลือ
หน้าครอบครัวมีแผนผังครอบครัวและสายอาจารย์-ศิษย์ พร้อมสถานะชีวิต

รองรับมือถือ: ตัวอักษรอ่านง่าย ปุ่มไม่เล็ก ไม่ใช้สีอย่างเดียวบอกความเสี่ยง มีข้อความแทนไอคอน
ยืนยันก่อนการกระทำเสี่ยงถึงชีวิต และมี autosave/คำเตือนข้อมูลหายตามที่เหมาะสม

# 16. สถาปัตยกรรมข้อมูลและความเสถียร

**ต้องตรวจโค้ดจริงก่อนตัดสินใจ** ห้ามสมมติชื่อไฟล์หรือ framework

หลักการ: แหล่งข้อมูลหลักเดียวสำหรับสถานะสำคัญ ใช้ ID ถาวร แยก definitions จาก
save data ให้การเปลี่ยนสถานะผ่านฟังก์ชันที่ตรวจเงื่อนไข มี migration เมื่อ schema
เปลี่ยน ตรวจ reference ก่อนลบข้อมูล และเก็บประวัติของเหตุการณ์สำคัญ

ข้อมูลตัวละครที่ควรตรวจว่าครบ: identity อายุ สถานะชีวิต สุขภาพ/อวัยวะ ค่าสถานะ วิชา
อาชีพ/สำนัก/ตำแหน่ง เป้าหมาย ความกลัว ความสัมพันธ์ ความทรงจำ ทรัพย์สิน/หนี้ เหตุการณ์
ครอบครัว/ผู้สืบทอด และตำแหน่ง รวมถึงบทบาทราชสำนัก (ฮ่องเต้ ฮองเฮา สนม ขันที
รัชทายาท ขุนนาง) ผู้สนับสนุน/ผู้ใต้บังคับบัญชา ความชอบธรรม ความลับ และสิทธิ์เข้าถึง

ข้อมูลโลก: ปี/ยุค ภูมิภาค/เศรษฐกิจ ราชวงศ์ ผู้ปกครอง สำนัก/กำลังคน
ความสัมพันธ์ระหว่างฝ่าย วิกฤต ข่าวลือ ตัวละครสำคัญและประวัติศาสตร์ รวมถึงสถานะ
การสืบทอดบัลลังก์ ฝ่ายการเมือง เครือข่ายอุปถัมภ์ หลักฐานคดี และประวัติการเปลี่ยนตำแหน่ง

Validation ต้องตรวจอายุไม่ติดลบ คนตายไม่ทำกิจกรรม
คนถูกจับไม่ปรากฏที่อื่นโดยไม่มีเหตุการณ์หนี วิชาไม่อ้าง ID ที่หาย บาดแผลสอดคล้องกับตัวเลือก
เงินไม่เป็น NaN/ติดลบโดยไม่มี rule ID ไม่ซ้ำ ความสัมพันธ์ไม่ชี้ข้อมูลหาย
การเปลี่ยนรุ่นไม่คืนชีพตัวละคร และโหลดเซฟไม่จ่ายรางวัลซ้ำ

หากเหมาะสม เพิ่ม seed/log สำหรับการสุ่ม เครื่องมือจำลองปีแบบไม่ใช้ UI
เครื่องมือสร้างประชากรทดสอบ รายงาน reference เสีย event-condition tests
และทดสอบ migration ไม่จำเป็นต้องเปิดเครื่องมือเหล่านี้ให้ผู้เล่นทั่วไป

# 17. สมดุลและการทดสอบ

อย่าปรับสมดุลจากความรู้สึกอย่างเดียว ควรมี simulation และ playtest

ทดสอบ: สร้างตัวละครจำนวนมากจากภูมิหลังต่างกัน จำลองหลายสิบ/หลายร้อยปี
ตรวจการกระจายระดับพลัง อายุขัยและสาเหตุการตาย รายได้รายจ่าย อัตราชนะตามเปอร์เซ็นต์
ความถี่บาดแผลรุนแรง การแต่งงาน/มีลูก การเติบโตประชากร วัฏจักรสงคราม
ความเป็นไปได้ของทุกอาชีพ การเปลี่ยนรุ่น และว่ากิจกรรมหนึ่งครอบงำทุกทางเลือกหรือไม่

หาก UI แสดงสำเร็จ 60% ให้จำลองซ้ำจำนวนมากและตรวจอัตราจริง โดยแยก modifiers
กรณีตัวอย่างเล็กอาจคลาดเคลื่อนได้ แต่ห้ามเบี่ยงเบนอย่างเป็นระบบเพราะ bug

ทดสอบกรณีสุดขั้ว: ไม่มีวิชา พิการตั้งแต่เด็ก รวยมาก ยากจนและมีหนี้ ฆ่าคนสำคัญตั้งแต่ต้น
ไม่เข้าร่วมสำนัก เล่นเป็นพ่อค้า/แพทย์ตลอดชีวิต มีลูกมาก ไม่มีทายาท สำนักถูกทำลาย
ราชวงศ์ล่มหลายครั้ง โลกมีโรคระบาด เล่นหลายรุ่น และโหลดเซฟกลางเหตุการณ์
รวมถึงกรณีฮ่องเต้สิ้นพระชนม์โดยไม่มีรัชทายาทชัดเจน ฮองเฮาสูญเสียผู้สนับสนุน
ขันทีถูกโยกย้าย/เปิดโปง ข้อมูลข่าวลือขัดกับหลักฐาน และการสืบทอดเปลี่ยนผลลัพธ์ข้ามรุ่น

คำถาม playtest: ผู้เล่นเข้าใจความเสี่ยงไหม ปีหนึ่งนานไปหรือไม่ มีทางเลือกดีที่สุดเสมอไหม
ผูกพันกับ NPC หรือไม่ ความพ่ายแพ้สร้างเรื่องใหม่หรือทำให้หงุดหงิดอย่างเดียว
อยากเริ่มรุ่นใหม่ไหม เล่าเรื่องที่เกิดขึ้นได้ไหม และ UI ทำให้ข้อมูลล้นหรือไม่

# 18. ลำดับพัฒนาและจุดตรวจ

## Phase 0 --- Audit & Baseline

ตรวจไฟล์ สถาปัตยกรรม core loop แหล่งข้อมูลตัวละคร/โลก/เหตุการณ์ save/load ระบบสุ่ม
combat/NPC/relationships/generations UI มือถือ test/build/lint
แล้วจัดระบบเป็น Existing / Partial / Missing / Broken / Needs verification
พร้อม dependency

**ผ่านเมื่อ:** มีรายงานที่อ้างอิงไฟล์จริง และบันทึก baseline ก่อนแก้ไข

## Phase 1 --- Core Year Loop

ทำโครงสร้างปี สถานะ ผลกิจกรรม สรุปผล บันทึกเหตุการณ์ และการข้ามเวลา

**ผ่านเมื่อ:** เล่นหนึ่งชีวิตได้โดยไม่มีผลซ้ำหรือรางวัลซ้ำ

## Phase 2 --- Goals & NPC Memory

เพิ่ม/ผสานเป้าหมายชีวิต ความทรงจำ ขอบเขตความรู้ การตัดสินใจ NPC
และความสัมพันธ์หลายแกน

**ผ่านเมื่อ:** NPC ตัดสินใจตามเป้าหมายและข้อมูลที่รู้จริง

## Phase 3 --- Combat & Injury

ทำสูตรโอกาส ความเสี่ยง บาดแผล ทางเลือกหลังพิการ การปรับตัวของคู่ต่อสู้ และทดสอบอัตรา

**ผ่านเมื่อ:** UI ตรงสูตรและไม่มีบาดแผลที่ทำให้เล่นต่อไม่ได้โดยไม่มีเหตุผล

## Phase 4 --- Relationships & Household

ครอบครัว คู่สมรส ลูก ศิษย์ อาจารย์ มรดกและผู้สืบทอด

**ผ่านเมื่อ:** ความสัมพันธ์เปลี่ยนจากเหตุการณ์จริงและส่งผลต่อการสืบทอด

## Phase 5 --- Sect, Economy & Politics

สำนัก ฝ่าย เศรษฐกิจ การบริหาร ราชสำนัก การเมืองฝ่ายใน (ฮ่องเต้ ฮองเฮา สนม ขันที
รัชทายาท ขุนนาง) เครือข่ายข่าวสาร/อุปถัมภ์ และการเปลี่ยนยุค

**ผ่านเมื่อ:** โลกเติบโต/เสื่อมได้โดยไม่ต้องรอผู้เล่นสั่งทุกครั้ง และการเปลี่ยนตำแหน่ง
หรือวิกฤตสืบทอดมีเหตุผล ตรวจสอบย้อนหลังได้ และส่งผลไปยังระบบอื่นจริง

## Phase 6 --- Generations & Chronicle

การตาย ผู้สืบทอด กฎการส่งต่อ ประวัติศาสตร์และตำนาน

**ผ่านเมื่อ:** เล่นหลายรุ่นโดยข้อมูลต่อเนื่องและไม่ขัดแย้ง

## Phase 7 --- Content Expansion

สร้าง event schema, สายเรื่อง, callbacks, ตรวจการเกิดซ้ำและขยายอาชีพ/ภูมิภาค

**ผ่านเมื่อ:** เหตุการณ์เชื่อมระบบจริงและหลากหลาย ไม่ใช่ครบจำนวนอย่างเดียว

## Phase 8 --- Balance, UX & Polish

จำลองจำนวนมาก ปรับ UI มือถือ ประสิทธิภาพ save size onboarding และ playtest

**ผ่านเมื่อ:** ผู้เล่นใหม่เข้าใจ core loop และผู้เล่นเก่ามีเหตุผลให้เล่นต่อหรือเริ่มใหม่

# 19. Rubric มุ่งสู่คุณภาพระดับ 10/10

คะแนน 10/10 รับประกันไม่ได้ ให้ใช้ rubric นี้ประเมินจากหลักฐานจริง

  หมวด                น้ำหนัก หลักฐานที่ต้องพิสูจน์
  ----------------- ------- -------------------------------------
  Core loop             15% ปีมีจังหวะ ไม่ซ้ำซาก
  NPC/ความสัมพันธ์         15% เป้าหมาย ความทรงจำและการกระทำสมเหตุผล
  ทางเลือก/ผลตามมา       15% มีข้อแลกเปลี่ยนและผลระยะยาว รวมถึงการเมืองราชสำนัก
  ข้ามรุ่น/Chronicle       15% โลกจดจำอดีตและส่งผลถึงรุ่นใหม่
  สมดุล                  10% ไม่มีทางเลือกเดียวดีที่สุดและโอกาสตรง UI
  เนื้อหา                 10% เหตุการณ์หลากหลายและไม่ซ้ำง่าย
  UI/UX                  8% อ่านง่าย ตัดสินใจได้ รองรับมือถือ
  ความเสถียร              7% save/load และสถานะไม่เสีย
  ประสิทธิภาพ              5% จำลองโลกได้เร็วพอ

ก่อนปล่อย: ไม่มีบั๊กวิกฤตที่ทำให้เซฟเสีย ทุกหมวดได้อย่างน้อย 7/10 จากการทดสอบ Core
Loop/NPC/Consequences/Generations ต้องได้อย่างน้อย 8/10 และมี playtest
กับผู้เล่นหลายรูปแบบพร้อมแก้ไขตามผลจริง

## ขั้นที่ 4: Vertical slice ที่เล่นได้

# ข้อสรุป

Murim World มีแกนที่แข็งแรงอยู่แล้ว: ชีวิตรายปี วิชายุทธ์ ความสัมพันธ์ สำนัก การเมือง
ราชสำนัก/วังหลัง และการเล่นข้ามรุ่น จุดที่ควรลงทุนมากที่สุดไม่ใช่การเพิ่มระบบให้มากที่สุด
แต่คือการทำให้
**เป้าหมายตัวละคร ความทรงจำ NPC เหตุการณ์โลก และผลจากการตัดสินใจ
เชื่อมต่อกันอย่างน่าเชื่อถือ**

หากทำได้ ผู้เล่นจะไม่ได้เพียงสะสมพลัง แต่สร้างประวัติศาสตร์ของตนเอง บางชีวิตเป็นวีรบุรุษ
บางชีวิตล้มเหลว บางตระกูลรุ่งเรือง บางสำนักล่มสลาย
และคนรุ่นหลังต้องอยู่กับผลของสิ่งที่คนรุ่นก่อนทำไว้

เป้าหมายไม่ใช่เกมที่มีทุกระบบ
แต่เป็นเกมที่ระบบหลักช่วยกันสร้างเรื่องราวที่ผู้เล่นอยากเล่าให้คนอื่นฟัง
และอยากกลับมาเริ่มชีวิตใหม่เพื่อดูว่าโลกจะเปลี่ยนไปอย่างไรอีกครั้ง
